# Target interpreter: Python 3.8, 3.9, or 3.10 (the D4RL / mujoco-py era).
#
# -----------------------------------------------------------------------------
# IMPORTANT INSTALL NOTES (read before `pip install -r requirements.txt`)
# -----------------------------------------------------------------------------
# 1) D4RL MUST be installed from a commit dated BEFORE June 2024 . The PyPI
#    `d4rl` package and post-June-2024 git commit drift away from the datasets
#    and environment semantics used in the paper (reward scales, goal
#    definitions, `antmaze-large-diverse-v2` contents). Install it explicitly:
#
#        pip install git+https://github.com/Farama-Foundation/d4rl@\
#            <pre-June-2024-commit-sha>
#
#    We intentionally do NOT pin `d4rl` in this file (see the commented block
#    at the bottom) because a plain `d4rl` requirement would pull the wrong
#    release.
#
# 2) MuJoCo: the paper/D4RL stack was built against MuJoCo 2.1 with
#    `mujoco-py`. If you use the newer `mujoco` (>=2.3) bindings, D4RL's
#    `antmaze` / `kitchen` environments may behave differently, so prefer
#    `mujoco-py==2.1.2.14` + `mujoco210` for exact reproduction.
#
# 3) ExORL RND datasets (walker / cheetah) are NOT pip-installable; they are
#    downloaded separately and placed under `./data` (see README). We require
#    `dm_control` (optional) only if you want to run the live simulators rather
#    than the offline dataset-replay fallback implemented in `fre/envs/`.
#
# 4) FB (Forward-Backward) and SF (Successor Features) baselines are NOT
#    reimplemented here. Run them from:
#        https://github.com/facebookresearch/controllable_agent
#    (DDPG + ICM features on the same ExORL RND data).
#
# 5) A CUDA GPU (>=16 GB) is strongly recommended: the full reproduction is
#    ~1M encoder steps + ~1M z-conditioned IQL steps per domain per seed.
#    All code paths fall back to CPU, but full runs will be prohibitively slow.
# =============================================================================
