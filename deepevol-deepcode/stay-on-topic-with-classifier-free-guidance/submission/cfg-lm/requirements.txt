# * torch is listed with the CUDA 12.1 wheel index; swap the index URL for

#   decoding, temperature 0.0, top-p 1.0). Per the plan, the harness version
#   must be pinned since defaults are used unless otherwise specified.
# * `human-eval` provides OpenAI's execution sandbox used by
#   src/eval/humaneval_eval.py (a self-contained subprocess fallback also
#   exists, so the package is optional but recommended).
