# SAPG: Split and Aggregate Policy Gradients -- dependencies
# ---------------------------------------------------------------
# Python 3.8 - 3.10 is required (see paper reproduction environment setup).
#
# Notes:
#   * torch must be a CUDA build for the paper's N = 24576 IsaacGym setting.
#   * IsaacGym is NOT distributed on PyPI. Install it separately following
#     NVIDIA's instructions (https://developer.nvidia.com/isaac-gym) and make
#     sure the `isaacgym` / `isaacgymenvs` packages are importable. When they
#     are absent the environment facade transparently falls back to a pure
#     PyTorch surrogate (`SAPG_FORCE_SURROGATE=1` forces it explicitly).
#   * scikit-learn / matplotlib / tensorboard / wandb are optional: the code
#     degrades gracefully when they are missing (numpy SVD fallback for PCA,
#     no-op plotting, console-only logging).
