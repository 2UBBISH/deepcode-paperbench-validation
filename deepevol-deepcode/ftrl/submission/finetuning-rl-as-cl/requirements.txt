# Notes
# -----
# * The four knowledge-retention mechanisms (src/retention/*), the toy
#   examples (src/toy/*) and the whole analysis stack (src/analysis/*) only

#   `--stub` implementations in that case).
# * `nle` (NetHack Learning Environment) must be built from source:
#       pip install git+https://github.com/heiner/nle.git
#   and requires a C toolchain + `cmake` (+ node/npm for the NetHack build).
# * Meta-World v2 environments are used for RoboticSequence; the Continual
#   World task ordering (Wolczyk et al., 2021) follows the same naming.
