# DeepCode（Paper2Code 线）现状 · 2026-09-21

依据代码整理（分支 `0916onmain-experiment`，最新提交 `4b5cac6ab`），面向对外说明；细节出处在各节末尾标注文件。

## 1. 一句话

DeepCode 引擎（vendored 于 `apps/v2/agent_engine/paper2code/`）被 `apps/v2/agent/paper2code/` 这一层包成一条**按目录、按阶段、可重跑**的流水线：论文 → 蓝图 → 参考仓库 → 代码树 → 摆卷判分。对比口径**只到第 9 步**（生成代码树，不租机、不执行、不修复），第 10 步（远程环境 + 试跑 + 修复）单独验证，不进入 PaperBench 分数。

## 3. 原文保真 —— ADR 0004"蓝图本身就是绑定"（默认开，`DEEPCODE_PAPER_FIDELITY=1`）

取代 09-20 的 ADR 0003（义务表 + 逐字引文 + 锚点回执 + 审计闸），那套在 50 篇 plan 压测里 12/12 首批全死在自己的格式层。

**规划侧**（`paper_readback.PLANNING_FIDELITY_ADDENDUM`）
- 第 2 节每个实现论文内容的组件段落写：文件路径 + `Source: §x.y[, §z]`。只指节，**不抄公式、不抄 LaTeX、不写引文**。
- glue 文件（包标记、配置、画图、README）不写；论文没给的值写 `Source: not specified in the paper` 并选默认。

**host 机械读回**（`source_fidelity.compile_manifest`，不问模型）
- 第 2 节按段落切；段落里出现的 `file_structure` 文件 → 绑到该段解析成功的每个节；多段并集；第 2 节没提到的文件 = glue。
- 指针解析容错：`§3.4 Initialization`、`4.1.`、带括号、`Table 3`/`Eq.(6)` → 承载它的节、范围 `§6.1-§6.4`、引号标题、目录段落 `models/` 绑其下全部计划文件；编号标题优先于示例里的 `#### 1`。
- 产物 `source_manifest.json`：`files[path].sections / glue / unmatched / orphan_pointers / pointers`。目前实测绑定率：fre 19/30 文件、rice 30/59、sapg 24/44、bbox 44/60、lbcs 20/33、lca 24/53；剩余 unmatched 基本是 md 里没有的表/图标题。

**写码侧**（`ReadPaperTool` + `FidelitySession`）
- 写码 agent 只有三个工具：`write_file`、`search_code_references`、`read_paper`（**没有执行工具**）。
- `read_paper(file_path=X)` 返回 X 的**下一个未读 (节, 页)**（长节按 3000 字分页），并列出还剩什么没读；调用到"nothing unread"为止。
- `write_file(X)` 放行条件：X 的**每个绑定节的每一页**都在**更早的模型回合**读过；否则 `SOURCE_READ_REQUIRED` 列出未读页。计划外文件允许写、不绑。
- 提示词：`IMPLEMENT_SYSTEM_ADDENDUM` / `ROUND_FIDELITY_ADDENDUM` / `GUIDANCE_FIDELITY_LINE`（"论文是规格，蓝图是摘要；论文和蓝图不一致以论文为准"）。

**审计只记录**（`source_fidelity.audit`）
- 实现结束回放 trace：回执属不属于该文件、早不早于写、最终字节是否等于最后一次记录的写、树与计划的差（按 basename 比对，`__init__.py` 永不算计划外）、页覆盖。
- 结果进事件 `implement.paper_fidelity` 和阶段记录，**不让阶段失败**；`implementation_status` 闸只把它放进 detail。
- ADR 0003 的义务 id / kind / 锚点 / JSON 绑定调用 / unassigned 重规划 / 审计闸门全部删除。

## 4. "第 10 步之前不执行"规则 + 静态语法检查（owner 09-20）

- 写码 agent 无 `execute_*` 工具；上游生成后的 `python3 -m pytest` 验证默认关（`PAPER2CODE_IMPLEMENT_VERIFY=1` 恢复），阶段记录 `inner_status: unverified / verification_disabled`，事件 `implement.execution`。
- 桌面端（Codex / Claude）对等规则：命令允许，只有长时间 CPU/GPU 训练或评估不允许，代码后续远程运行；审计 >10 min 单条（安装除外）/ >60 min 总计 → `CALIBER_BROKEN`（验证仓库分支 `0919-test`）。
- 线上的 `py_compile` 对等物：`syntax_check.py` —— 生成后 `compile()` 每个 `.py`（只解析，不导入不运行），有错则用修复 agent（`read_text_file` / `edit_file`，无容器）修，最多 `DEEPCODE_SYNTAX_ROUNDS=2` 轮；保真开时修复轮跑在 `FidelitySession` 里（改被指文件前先 `read_paper`，编辑记进 trace）。剩余错误记录不致命。`DEEPCODE_SYNTAX_CHECK=0` 关。
