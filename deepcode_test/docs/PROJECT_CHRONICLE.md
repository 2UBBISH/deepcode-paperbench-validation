## 0. 缘起

用户的真实需求是**自建一个论文复现 agent**(论文 → 环境 + 代码 → 数据 → CPU/GPU 复现 → 结果),约束是不能接 Claude Code 壳、没有 Anthropic API,模型只能走 OpenAI 兼容端点。DeepCode(HKUDS,arXiv:2512.07921)是唯一有成果、有代码的同类开源项目,论文声称其脚手架让复现效果达到商业编码工具的 1.34×(fre)/ 1.95×(rice)。**在把它当参考基线之前,先验证它的声称是否成立、成立在哪** —— 这就是本项目。

评测口径沿用论文自己的:PaperBench Code-Development(只审代码不执行,SimpleJudge 二值叶加权),裁判固定为一个模型。

## 8. 双裁判重判:结论翻转(09-03 上午)

- fre(Paratera):anchor 0.5044、bare_v4 0.4807、trial1 0.4682、trial5 0.3101、**fx1 0.3618、fx2 0.4873**。修复轮没有恢复增益;维度分解显示**基线从全 0 变有分,但 FRE 主方法从 0.82 跌到 0.26(fx1)/0.70(fx2)**——反事实"补基线 → 1.35×"被推翻。
- 用户:"总预算固定是为什么?为什么不是根据仓库动态定预算?" → 代码坐实预算是常量;但复核后更正:fx1 没撞任何硬预算、核心文件也没变薄,主方法是**写错了**而不是写少了;"预算零和"叙事是过拟合两个数据点。用户:"有没有更好的方法,避免只是对现在数据集过拟合" → 提出四条不依赖数据集的原则与方法论(留出集、预注册、禁用评分表信息、跨模型、n≥5)。
- 用户:"开个子 agent review 一下自己的改动" → 独立审查发现:**纪律 A("默认值一字未改")不成立,15 处未门控**;**纪律 B 一处违规**——fix-①② 提示词含 "Graders assign separate credit to each baseline";明文 key;fix-③ 编译到错文件。用户:"这一轮的修复提交先重置掉" → fx1/fx2 整体作废(产物保留供机制分析)。
- rice(Paratera):**bare_v4 0.4680 → 0.1452**、trial2 0.4033、trial3 0.3446、bare_kimi 0.1865、k1 0.2403、k2 0.3754。倍数 **1.05× → 2.58×**、**0.82× → 1.65×**。诊断:两裁判输入 token 几乎相同(60.8k vs 62.9k)、输出减半、45 个叶 1→0;同一段代码一个判"可配置为四层 MLP 满足",一个判"未实例化不满足"——严格裁判专门惩罚"抽象类 + 可配置参数"写法。
- 用户:"我们之前跑过 judgeeval 啊" → 用 Paratera 裁判重跑 JudgeEval(¥28):**F1 0.719 vs 0.685,通过率与偏向完全相同,叶级一致 84.3%**;差异在噪声内,样本(作者仓库)不覆盖分歧区间 → **裁不了**。
