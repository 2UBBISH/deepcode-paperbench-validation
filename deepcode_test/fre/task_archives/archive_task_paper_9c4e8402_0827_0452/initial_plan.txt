  # SECTION 2: Implementation Components
  implementation_components: |
    ## 1. Prior Reward Distribution (reward_functions.py)
    - **Purpose**: Generate diverse random unsupervised reward functions for training.
    - **Mixture of three types** (uniform sampling):
      a) **Singleton Goal-Reaching**: Reward = -1 for every timestep where goal not reached, 0 otherwise. Goal state sampled uniformly from dataset states.
      b) **Random Linear Functions**: Reward = dot(w, s) where w ~ Uniform(-1,1) with sparse mask (e.g., 80% zeros) to bias towards simple functions.
      c) **Random MLPs**: 2-layer MLP with random initialization (weights ~ Xavier uniform, biases ~ Uniform(-0.1,0.1)), hidden dim 256, ReLU activation. Output single scalar reward.
    - **Implementation**: Class `PriorRewardDistribution` with method `sample()` returning a callable reward function `η(s)`.

    ## 2. FRE Encoder (fre_encoder.py)
    - **Purpose**: Encode a set of (state, reward) pairs into a latent representation z.
    - **Architecture**: Permutation-invariant transformer (no positional encodings, no causal masking).
      - Input: K encoder states {s_k^e} and their scalar rewards {η(s_k^e)}.
      - Reward discretization: Scalar reward is discretized into a learned embedding token space (e.g., 256 bins, embedding dim 64). Alternatively, use a small MLP to embed continuous reward.
      - State embedding: Linear projection of state to embedding dim (e.g., 128).
      - Concatenate reward embedding and state embedding as input tokens.
      - Transformer: 3 layers, 4 attention heads, feedforward dim 512, dropout 0.1.
      - Output: Average of final layer representations across all K tokens.
      - Two linear projections (mean and log_std) to parameterize Gaussian distribution p_θ(z | {(s_k^e, η(s_k^e))}).
      - Latent dimension: 64 (or 128).
    - **Implementation**: Class `FREEncoder` with `encode(context_pairs)` returning mean, log_std; `sample_z(mean, log_std)` using reparameterization trick.

    ## 3. FRE Decoder (fre_decoder.py)
    - **Purpose**: Predict reward for a given state s conditioned on latent z.
    - **Architecture**: Feedforward neural network.
      - Input: Concatenation of state s and latent z.
      - Hidden layers: 3 layers, dims [256, 256, 256], ReLU activation.
      - Output: Single scalar predicted reward η̂(s).
    - **Implementation**: Class `FREDecoder` with `forward(s, z)`.

    ## 4. VAE Training Loss (Equation 6)
    - **Loss**: L = MSE(η̂(s_k^d), η(s_k^d)) + β * KL( N(μ, σ^2) || N(0, I) )
      - Reconstruction: Mean squared error between predicted and true rewards on K' decoder states (sampled independently from encoder states).
      - KL divergence: Standard Gaussian prior, β=1.0 (or tuned).
    - **Training**: Jointly train encoder and decoder. Optimizer: Adam, lr=1e-4, batch size 256 reward functions, each with K=32 encoder states, K'=32 decoder states.

    ## 5. IQL Networks (iql_networks.py)
    - **Purpose**: Offline RL components conditioned on latent z.
    - **Q-function**: Q(s, a, z) - MLP with 3 hidden layers [256,256,256], input: state s, action a, latent z concatenated.
    - **Value function**: V(s, z) - MLP with 3 hidden layers [256,256,256], input: state s, latent z.
    - **Policy**: π(a|s, z) - Gaussian policy (for continuous actions) or Categorical (for discrete). MLP with 3 hidden layers [256,256,256], output mean and log_std. For AntMaze (8-DoF), continuous actions.
    - **IQL Losses**:
      - Value loss: L_V = E[(τ - Q(s,a,z))^2] where τ is expectile (e.g., 0.7) regression target.
      - Q loss: L_Q = E[(r + γ V(s',z) - Q(s,a,z))^2] with target network.
      - Policy loss: L_π = E[exp(β * (Q(s,a,z) - V(s,z))) * log π(a|s,z)] (advantage-weighted regression, AWR).
    - **Implementation**: Classes `IQLQNetwork`, `IQLValueNetwork`, `IQLPolicy`, with methods for loss computation.

    ## 6. Training Procedure (Algorithm 1)
    - **Phase 1: Encoder Training** (train_encoder.py)
      - Loop until convergence (e.g., 100k steps):
        - Sample reward function η ~ p(η).
        - Sample K=32 encoder states {s_k^e} from offline dataset.
        - Sample K'=32 decoder states {s_k^d} from offline dataset.
        - Compute encoder output (μ, σ), sample z.
        - Decode rewards for decoder states, compute VAE loss.
        - Backpropagate, update encoder and decoder.
    - **Phase 2: RL Training** (train_rl.py)
      - Freeze encoder weights.
      - Loop until convergence (e.g., 1M steps):
        - Sample reward function η ~ p(η).
        - Sample K=32 encoder states, encode to z (deterministic: use μ).
        - Sample batch of (s, a, s') from offline dataset.
        - Compute rewards r = η(s).
        - Compute IQL losses for Q, V, π conditioned on z.
        - Update Q, V, π networks.
    - **Strided training**: Phase 1 first, then Phase 2. No joint training.

    ## 7. Zero-Shot Evaluation (evaluate.py)
    - **Input**: Trained FRE encoder (frozen), trained IQL policy (conditioned on z).
    - **For each downstream task** (e.g., goal-reaching, directional):
      - Define true reward function η_test (e.g., goal location, velocity direction).
      - Sample K=32 states from dataset, compute rewards, encode to z_test.
      - Rollout policy π(a|s, z_test) in environment for 20 episodes.
      - Compute average normalized return (0-100 scale).
    - **Normalization**: Return normalized by max possible return or baseline random policy return.

    ## 8. Baselines (for comparison)
    - **FB**: Forward-Backward representations (Touati & Ollivier, 2021). Use provided code, evaluate with 5120 reward samples.
    - **SF**: Successor Features with ICM features. Use provided code.
    - **GC-IQL**: Goal-conditioned IQL with hindsight relabeling. Implement in same codebase.
    - **GC-BC**: Goal-conditioned behavioral cloning. Implement.
    - **OPAL**: Skill discovery via trajectory autoencoding. Re-implement.
