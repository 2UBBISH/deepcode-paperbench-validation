  implementation_components: |
    A. Offline dataset loader
       - Locations: fre/dataset.py, envs/*.py
       - Load D4RL AntMaze-large-diverse-v2, D4RL Kitchen, and ExORL
         walker/cheetah exploratory datasets.
       - Maintain a state-action transition dataset and a separate state-only pool
         for reward-prior sampling and FRE context sampling.
       - Normalize states to mean 0 and std 1 using dataset statistics.
       - AntMaze: expose (x,y,theta,...) states and 8D actions.
       - Kitchen: expose D4RL state space and 7 subtask indices.
       - ExORL: load DeepMind Control Suite walker/cheetah exploratory data.

    B. Random reward prior distribution
       - Location: fre/reward_prior.py
       - Uniform mixture of three reward-function classes:
         1. Singleton goal-reaching rewards:
              eta(s) = -1 if ||s - g|| > epsilon else 0
              where g ~ Uniform(offline state pool), epsilon is goal threshold.
         2. Random linear rewards:
              eta(s) = <w, s>
              where w ~ Uniform(-1, 1)^state_dim, sparsified by Bernoulli mask
              with p_mask ~ 0.6-0.9 to bias toward simple functions.
         3. Random MLP rewards:
              eta(s) = MLP_{2-layer}(s)
              hidden dim 256, ReLU, scalar output; weights randomly initialized.
       - Sample reward class uniformly, then sample its parameters.
       - Clip all rewards to [-1, 1] during training.
       - Interface: sample_reward_fn() -> callable(s) -> scalar reward.

    C. Reward discretization and learned embedding
       - Location: fre/reward_embedding.py
       - Discretize scalar rewards into learned embedding tokens.
       - B reward bins over [-1, 1]; for scalar reward r:
             bin_idx = clamp(floor((r + 1) * B / 2), 0, B - 1)
       - Learned embedding table: nn.Embedding(B, embedding_dim=64).
       - Default B = 64.
       - Token representation:
             state_tok = Linear(state_dim, 192)(s)
             reward_tok = Embedding(bin_idx)
             token = Linear(192 + 64, 256)([state_tok, reward_tok])
       - No positional encoding; no causal mask.

    D. FRE encoder: permutation-invariant transformer VAE
       - Location: fre/encoder.py
       - Input: set of K tokens corresponding to (s_k, eta(s_k)).
       - Transformer encoder:
             d_model = 256
             nhead = 4
             num_layers = 3 or 4
             activation = GELU
             dropout = 0.1
             no positional encoding
             causal mask disabled
       - Treat K inputs as unordered set.
       - Average final-layer token representations into vector h.
       - Two linear projection heads:
             mu = Linear(256, latent_dim)(h)
             logvar = Linear(256, latent_dim)(h)
       - Reparameterization:
             z = mu + exp(0.5 * logvar) * eps, eps ~ N(0, I)
       - Default latent_dim = 128.

    E. FRE decoder
       - Location: fre/decoder.py
       - Input: state s and latent z.
       - MLP:
             [s, z] -> Linear(input_dim, 256) -> ReLU
                   -> Linear(256, 256) -> ReLU
                   -> Linear(256, 1)
       - Predicts scalar reward eta(s).
       - Decoder states K' sampled independently from encoding states;
         default K' = 256.

    F. FRE VAE training objective
       - Location: fre/fre_vae.py
       - For sampled reward function eta:
             sample K encoder states {s^e_k} and K' decoder states {s^d_k}
             encode z ~ p_theta(z | {(s^e_k, eta(s^e_k))})
             decode r_hat^d = q_theta(eta(s^d) | s^d, z)
       - Loss:
             L_recon = ||eta(s^d) - r_hat^d||^2
             L_kl = 0.5 * sum(1 + logvar - mu^2 - exp(logvar))
             total = mean(L_recon) + beta * mean(L_kl)
       - Default beta = 1.0, optimizer Adam, lr = 1e-4.
       - Train until reconstruction converges on all three reward families.

    G. Strided training procedure
       - Locations: scripts/train_fre_encoder.py, scripts/train_rl.py
       - Phase 1: train only FRE encoder/decoder with VAE objective.
         Do not train RL components.
       - After encoder loss converges, freeze encoder weights.
       - Phase 2: train IQL RL networks using frozen encoder outputs.

    H. FRE-conditioned offline RL with IQL
       - Locations: fre/iql.py, fre/agent.py
       - Networks:
             Q1, Q2: MLP 256x256, input [state, action, z], scalar output.
             V:      MLP 256x256, input [state, z], scalar output.
             Policy: MLP 256x256, input [state, z],
                     Gaussian mean/logstd; action squashed by tanh.
       - Per training iteration:
             1. Sample B transitions from offline dataset.
             2. Sample B reward functions eta_i from reward prior.
             3. For each eta_i, sample K encoder states, evaluate rewards,
                encode to z_i using frozen FRE encoder.
             4. Compute r_i = eta_i(s_i).
             5. Update IQL on transitions (s_i, a_i, r_i, s'_i, z_i).
       - IQL losses:
             V loss (expectile tau = 0.9):
                 L_V = E[ L_tau^2(Q_target(s,a,z) - V(s,z)) ]
                 L_tau^2(u) = |tau - 1_{u < 0}| * u^2
             Q loss:
                 L_Q = E[ (r + gamma * V(s',z) - Q(s,a,z))^2 ]
                 gamma = 0.99
             Policy loss (advantage-weighted regression):
                 L_pi = -E[ exp((Q(s,a,z) - V(s,z)) / beta)
                            * log pi(a | s,z) ]
                 beta = 3.0, advantage clipped to [-5, 2]
       - Double Q learning: use min(Q1,Q2) for V target.
       - Target Q accuracy via Polyak averaging with tau = 0.005.
       - Optimizer Adam lr = 3e-4.

    I. Zero-shot evaluation
       - Location: scripts/eval_zero_shot.py, envs/*.py
       - For unseen downstream reward, collect exactly 32 state-reward examples
         by evaluating reward on 32 states from offline dataset.
       - Encode 32 pairs with frozen FRE encoder to obtain z.
       - Execute policy pi(a|s,z) in environment.
       - Report normalized task score between 0 and 100.
       - Mean over 20 evaluation episodes; 5 random training seeds.

    J. Evaluation task definitions
       - AntMaze-large-diverse-v2:
             ant-goal-reaching, ant-directional, ant-random-simplex,
             ant-path-loop, ant-path-edges, ant-path-center
       - ExORL walker/cheetah:
             walker-goals, cheetah-goals, walker-velocity, cheetah-velocity
       - Kitchen:
             seven standard subtask rewards.

    K. Baseline implementations
       - Locations: baselines/*.py, scripts/train_baselines.py,
         scripts/eval_baselines.py
       - Forward-Backward (FB):
           * Jointly learns forward F(s,a,z) and backward B(s,a,z) representations.
           * DDPG-based policy and Q networks.
           * Linearized value representation.
           * Evaluation uses 5120 reward samples for ridge/linear regression
             to select task embedding.
       - Successor Features (SF):
           * Learn successor features over ICM-pretrained state features
             (Pathak et al. 2017), following Touati et al. 2022.
           * DDPG-based policy and Q networks.
           * Evaluation uses linear reward regression with 5120 samples.
       - Goal-Conditioned IQL (GC-IQL):
           * IQL with hindsight relabeling to learn goal-reaching policies.
           * Goal-conditioned Q/V/policy networks; same network sizes as FRE.
       - Goal-Conditioned Behavioral Cloning (GC-BC):
           * Goal-conditioned policy trained by behavioral cloning on
             trajectories that reach goals in the dataset.
       - OPAL:
           * Unsupervised skill discovery by auto-encoding trajectories
             into latent skills.
           * Trained with trajectory encoder/decoder and skill prior.
           * Evaluation is privileged: 10 skills evaluated with online
             rollouts, select highest downstream performance.

    L. Experiment-specific scripts
       - visualize_antmaze.py:

       - domain_prior_augmentation.py:

           * Reproduce Figure 6 domain-knowledge experiments.
