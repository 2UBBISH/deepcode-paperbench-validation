  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    1. PRIOR REWARD DISTRIBUTION (fre/prior.py)
    ============================================================
    Purpose: Generate random unsupervised reward functions η(s) from a mixture of three families.
    Classes:
      - GoalReachingReward: η(s) = -1 if goal not reached else 0. Goal state sampled uniformly from dataset.
      - LinearReward: η(s) = w^T s, w ~ Uniform(-1,1) with sparse mask (e.g., 80% zeros) to bias towards simple functions.
      - MLPReward: η(s) = MLP(s), a 2-layer MLP with random weights (hidden dim 256, ReLU).
      - MixturePrior: Uniformly samples one of the three types per call. Provides sample() -> reward_fn, and evaluate(reward_fn, states) -> rewards.
    Implementation details:
      - GoalReachingReward: store a set of goal states from dataset; at each call, pick a random goal; reward = -1 for all states except goal (distance threshold? Use L2 distance < ε, e.g., 0.5).
      - LinearReward: generate w with dim = state_dim; apply mask: each element zero with probability 0.8.
      - MLPReward: initialize a nn.Sequential(Linear(state_dim,256), ReLU, Linear(256,1)) with Kaiming uniform weights; freeze weights after init.
      - MixturePrior: __call__ returns a reward function wrapper that has a method get_reward(states) -> tensor.

    ============================================================
    2. FRE ENCODER (fre/encoder.py)
    ============================================================
    Purpose: Encode a set of (state, reward) pairs into a latent vector z via a permutation-invariant transformer VAE.
    Architecture:
      - Reward discretization: scalar reward → bin index → learned embedding.
        * Define B bins covering expected reward range (e.g., [-10, 10] for AntMaze, [-1,1] for ExORL). Use uniform binning.
        * Embedding table: nn.Embedding(num_bins, d_emb) where d_emb = 256.
      - State embedding: nn.Linear(state_dim, d_emb).
      - Input sequence: for each of K pairs, state_emb + reward_emb → token of size d_emb. (K=32)
      - Transformer encoder: nn.TransformerEncoder with num_layers=3, nhead=4, dim_feedforward=512, dropout=0.1. No positional encoding, no causal mask (set src_mask=None).
      - Aggregation: mean over K output tokens → single vector h.
      - Posterior: two linear heads from h to μ_z and log_σ_z (latent dim = 64). Sample z = μ + σ * ε, ε ~ N(0,I).
    Forward pass:
      Input: states (K, state_dim), rewards (K,)
      1. reward_bins = discretize(rewards) → (K,) indices
      2. reward_emb = embedding(reward_bins) (K, d_emb)
      3. state_emb = state_linear(states) (K, d_emb)
      4. tokens = state_emb + reward_emb (K, d_emb)
      5. tokens = tokens.unsqueeze(1)  # Transformer expects (seq, batch, dim); batch=1 for single encoding
      6. out = transformer(tokens) (K, 1, d_emb)
      7. h = out.mean(dim=0) (1, d_emb)
      8. μ, log_σ = mu_head(h), logvar_head(h)
      9. z = reparameterize(μ, log_σ)
      Return z, μ, log_σ

    ============================================================
    3. REWARD DECODER (fre/decoder.py)
    ============================================================
    Purpose: Predict reward η(s) given state s and latent z.
    Architecture: MLP that takes concatenated [s, z] and outputs scalar reward.
      - Input: state (state_dim), z (latent_dim=64) → concat → (state_dim+64)
      - Hidden layers: Linear(state_dim+64, 256), ReLU, Linear(256, 256), ReLU, Linear(256, 1)
    Forward: reward_pred = decoder(s, z)
    Loss: MSE(reward_pred, true_reward) averaged over K' decoder states.

    ============================================================
    4. VAE TRAINING LOSS (Equation 6)
    ============================================================
    Objective: maximize ELBO = E_{z~p_θ(z|s_e,η(s_e))}[log q_θ(η(s_d)|s_d,z)] - KL(p_θ(z|·) || p(z))
    Implementation:
      - Reconstruction: MSE_loss(decoder(s_d, z), η(s_d))
      - KL divergence: -0.5 * sum(1 + log_σ^2 - μ^2 - σ^2)  (assuming prior N(0,I))
      - Total loss = reconstruction_loss + β_kl * kl_loss (β_kl=1.0, but can be tuned)
    Note: The paper says "maximizing Equation (6)" – we minimize negative ELBO.

    ============================================================
    5. IMPLICIT Q-LEARNING (fre/iql.py)
    ============================================================
    Purpose: Offline RL algorithm that learns Q, V, and policy conditioned on z.
    Networks (all take z concatenated with state/action):
      - Q_network: input (s, a, z) → Q value. Architecture: Linear(state_dim+action_dim+latent_dim, 256), ReLU, Linear(256, 256), ReLU, Linear(256, 1)
      - V_network: input (s, z) → V value. Similar architecture.
      - Policy_network: input (s, z) → action distribution (Gaussian). Mean: Linear(state_dim+latent_dim, 256), ReLU, Linear(256, action_dim). Log_std: separate learnable parameter or head.
    Target networks: Polyak averaging (τ=0.005) for Q and V.
    Losses:
      - V loss: expectile regression L2^τ with τ=0.7.
          L_V = E_{(s,z)}[ L2^τ( Q_target(s, π(s,z), z) - V(s,z) ) ]
          where L2^τ(u) = |τ - 1(u<0)| * u^2
      - Q loss: MSE between Q(s,a,z) and r + γ * V_target(s',z). γ=0.99.
          L_Q = E_{(s,a,r,s',z)}[ (Q(s,a,z) - (r + γ*V_target(s',z)))^2 ]
      - Policy loss: advantage-weighted regression with β=3.0.
          A = Q(s,a,z) - V(s,z)
          L_π = E_{(s,a,z)}[ exp(β * A) * -log π(a|s,z) ]
    Training step:
      1. Sample batch (s, a, s') from dataset, sample η, compute r=η(s), encode z from K separate encoder states.
      2. Update V, Q, π using above losses with Adam (lr=3e-4).

    ============================================================
    6. FRE AGENT (fre/agent.py)
    ============================================================
    Purpose: Orchestrates encoder, decoder, IQL, and training loops.
    Methods:
      - train_encoder_phase(dataset, prior, steps): Phase 1 training.
          For step in range(steps):
            η = prior.sample()
            s_e = sample K states from dataset
            s_d = sample K' states from dataset (K'=64)
            r_e = η(s_e), r_d = η(s_d)
            z, μ, log_σ = encoder(s_e, r_e)
            r_pred = decoder(s_d, z)
            loss = MSE(r_pred, r_d) + KL(μ, log_σ)
            optimizer.zero_grad(); loss.backward(); optimizer.step()
      - train_rl_phase(dataset, prior, steps): Phase 2 training.
          Freeze encoder.
          For step in range(steps):
            Sample batch (s, a, s') from dataset (batch_size=256)
            η = prior.sample()
            s_e = sample K states from dataset
            r_e = η(s_e)
            with torch.no_grad(): z = encoder(s_e, r_e)[0]  # use mean only
            r = η(s)
            Update IQL with (s, a, r, s', z)
      - eval(test_reward_fn, env, dataset): Zero-shot evaluation.
          Sample K states from dataset, compute rewards, encode z (use mean).
          Run policy in env for N episodes, compute average return.

    ============================================================
    7. UTILITIES (fre/utils.py)
    ============================================================
    - discretize(rewards, num_bins, min_val, max_val): map scalar rewards to bin indices.
    - sample_states(dataset, K): uniformly sample K states from offline dataset.
    - Dataset wrapper: loads D4RL/ExORL datasets, provides (s, a, s') tuples (no rewards). For AntMaze, Kitchen: use d4rl.qlearning_dataset; for ExORL: use custom loader.

      - transformer_layers: 3
      - transformer_heads: 4
      - latent_dim: 64
      - decoder_hidden: 256
      - iql_hidden: 256
      - τ (expectile): 0.7
      - β (AWR): 3.0
      - γ (discount): 0.99
      - lr: 3e-4
      - batch_size: 256

      - rl_steps: 1000000
      - target_update_rate: 0.005
