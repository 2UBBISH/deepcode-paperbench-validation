# Code Implementation Summary
**Generated**: 2026-08-27 20:40:28
**File Implemented**: fre/encoder.py

**Core Purpose**  
Implements a permutation-invariant transformer VAE encoder that maps a set of K (state, reward) pairs into a Gaussian latent vector z ~ N(μ, σ²I). This is the core encoding component of the Functional Reward Encodings (FRE) framework, enabling zero-shot generalization by representing arbitrary reward functions in a compact latent space.

**Public Interface**  
- **Class `RewardEncoder`**: Permutation-invariant transformer encoder for reward functions.  
  *Key methods*: `forward(states, rewards) -> (mu, logvar)`, `reparameterize(mu, logvar) -> z`, `encode_and_sample(states, rewards) -> (mu, logvar, z)`, `encode_deterministic(states, rewards) -> z`.  
  *Constructor params*: `state_dim` (int), `d_model` (int, default 256), `nhead` (int, default 4), `num_layers` (int, default 3), `d_z` (int, default 64), `num_reward_bins` (int, default 50), `reward_min` (float, default -1.0), `reward_max` (float, default 1.0), `dropout` (float, default 0.1), `ff_dim` (Optional[int], default None), `use_sum_tokens` (bool, default False).

- **Function `kl_divergence(mu, logvar) -> Tensor`**: Computes KL(N(μ,σ²I) || N(0,I)) per sample, averaged over latent dimensions.

- **Function `vae_loss(recon_loss, mu, logvar, beta=1.0) -> Tensor`**: Computes total VAE loss = reconstruction loss + β * KL divergence (scalar).

**Internal Dependencies**  
- From `typing`: `Tuple`, `Optional`  
- External packages: `numpy` (weight initialization), `torch`, `torch.nn`, `torch.nn.functional` (core neural network operations)

**External Dependencies**  
- Expected to be imported by: `fre/fre_agent.py` (training loop), `experiments/evaluate.py` (zero-shot evaluation), and indirectly by `fre/decoder.py` (though decoder does not import encoder, they are used together in the VAE pipeline).  
- Key exports used elsewhere: `RewardEncoder` class, `vae_loss` function.

**Implementation Notes**  
- **Architecture decisions**: Transformer encoder with no positional encoding and no causal mask, ensuring permutation invariance. Average pooling over output tokens aggregates the set representation. Reward values are discretized into `num_reward_bins` uniform bins and embedded; state is projected linearly. Token combination can be concatenation+projection (default) or summation.  
- **Cross-File Relationships**: The encoder is paired with `fre/decoder.py` (to be implemented) to form the VAE. It relies on `fre/reward_prior.py` for generating diverse reward functions during training, and on `fre/utils.py` for dataset sampling. The frozen encoder is later used by `fre/iql.py` and `fre/fre_agent.py` for conditioning the policy and value functions.
