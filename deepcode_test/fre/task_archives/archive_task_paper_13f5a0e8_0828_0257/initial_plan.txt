  # SECTION 2: Implementation Components
  implementation_components: |
    **1. Reward Prior Distribution (reward_prior.py)**
    - Purpose: Generate diverse unsupervised reward functions η(s) for training.
    - Three families mixed uniformly:
      a) Goal-reaching (singleton): η(s) = -1 if not at goal else 0. Goal state sampled uniformly from dataset states.
      b) Random linear: η(s) = dot(w, s) where w ~ Uniform(-1,1) with sparse mask (e.g., 80% zeros) to bias towards simple functions.
      c) Random MLP: 2-layer MLP with random weights (hidden dim 256, ReLU). Weights drawn from Kaiming uniform.
    - Implementation: class `RewardPrior` with method `sample()` returning a callable reward function and its type.

    **2. FRE Encoder (encoder.py)**
    - Purpose: Encode a set of K (state, reward) pairs into a latent vector z.
    - Architecture: Permutation-invariant transformer (no positional encoding, no causal mask).
      - Input: K pairs (s_i, r_i). Reward r_i is discretized into a learned embedding token space (e.g., 50 bins based on reward magnitude). State s_i is projected via linear layer to embedding dim. The two embeddings are concatenated (or summed) to form token.
      - Transformer: N layers (e.g., 3), M heads (e.g., 4), hidden dim D (e.g., 256). Feedforward dim 4*D.
      - Output: Average pooling over tokens → two linear heads for μ and log σ of Gaussian latent z (dim d_z, e.g., 64).
    - Formula: z ~ N(μ, σ² I) where [μ, log σ] = TransformerEncoder({(s_i, r_i)}_i=1^K).
    - K = 32 (as per paper).

    **3. FRE Decoder (decoder.py)**
    - Purpose: Predict reward η(s) for a query state s given latent z.
    - Architecture: MLP with 2-3 hidden layers (e.g., [256, 256]), input = concat(s, z), output = scalar reward.
    - Trained jointly with encoder to minimize MSE: L_recon = (1/K') Σ_{j=1}^{K'} (η(s_j^d) - q_θ(s_j^d, z))².
    - K' can be same as K or larger (e.g., 64).

    **4. VAE Training (in fre_agent.py, phase 1)**
    - Loss: L = L_recon + β * KL( N(μ, σ² I) || N(0, I) ), with β = 1.0 (or tuned).
    - Training loop (Algorithm 1, first while):
      - Sample η ~ p(η)
      - Sample K encoder states {s_k^e} from dataset D, compute rewards η(s_k^e)
      - Sample K' decoder states {s_k^d} from D (disjoint from encoder states)
      - Forward encoder → z, decoder → predicted rewards
      - Backprop L, update encoder+decoder parameters.
    - Convergence criterion: loss plateaus (e.g., after fixed steps or early stopping).

    **5. IQL Agent (iql.py)**
    - Purpose: Offline RL algorithm conditioned on latent z.
    - Components:
      - Policy π(a|s, z): Gaussian policy (for continuous actions) with tanh squashing; MLP [256,256] outputting mean and log_std.
      - Q-function Q(s, a, z): MLP [256,256] → scalar.
      - Value function V(s, z): MLP [256,256] → scalar.
    - IQL losses (from Kostrikov et al. 2021):
      - V loss: expectile regression L_V = E[(τ - 1_{Q - V < 0}) * (Q - V)²] with τ=0.7 (expectile).
      - Q loss: L_Q = E[(r + γ V(s', z) - Q(s,a,z))²] with γ=0.99.
      - Policy loss: L_π = E[exp(α * (Q - V)) * log π(a|s,z)] with α=3.0 (advantage-weighted regression).
    - All networks conditioned on z by concatenating z to input.

    **6. Strided Training Scheme (fre_agent.py, Algorithm 1)**
    - Phase 1: Train only encoder+decoder (FRE) until convergence (e.g., 100k steps).
    - Phase 2: Freeze encoder; train IQL networks (policy, Q, V) using frozen encoder outputs.
      - At each iteration: sample η, encode to z, sample batch (s,a,r,s') from D where r = η(s), compute IQL losses, update.
    - Important: encoder frozen ensures stationary z mapping for stable TD learning.

    **7. Zero-Shot Evaluation (evaluate.py)**
    - Given a new downstream reward function η_test (e.g., goal-reaching, directional).
    - Sample K=32 states from dataset, compute η_test(s), encode to z via frozen encoder.
    - Roll out policy π(a|s, z) in environment, compute average return over 20 episodes.
    - No fine-tuning.
