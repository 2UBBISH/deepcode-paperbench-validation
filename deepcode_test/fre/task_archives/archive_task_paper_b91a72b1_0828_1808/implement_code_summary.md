# Code Implementation Summary
**Generated**: 2026-08-28 14:50:36
**File Implemented**: fre/encoder.py

**Core Purpose**  
Implements the permutation-invariant Transformer VAE encoder that maps a set of (state, reward) pairs to a latent Gaussian distribution \( p_\theta(z \mid \{(s_i, \eta(s_i))\}) \). This is the core encoding component of the Functional Reward Encodings (FRE) model, enabling zero-shot generalization by compressing reward function information into a compact latent vector.

**Public Interface**  
- **Class `FREEncoder`**: Full encoder pipeline combining state embedding, reward discretization, Transformer, aggregation, and latent heads.  
  - Key methods:  
    - `encode(states, rewards) -> (mu, logvar)`: Produces distribution parameters.  
    - `reparameterize(mu, logvar) -> (z, kl)`: Samples latent vector and computes KL divergence.  
    - `forward(states, rewards) -> (z, mu, logvar, kl)`: Full encode + sample.  
    - `encode_deterministic(states, rewards) -> z`: Returns mean without sampling (for evaluation).  
  - Constructor params: `state_dim`, `d_model=256`, `d_reward=32`, `d_latent=64`, `num_bins=50`, `r_min=-1.0`, `r_max=1.0`, `nhead=4`, `num_layers=4`, `dim_feedforward=1024`, `dropout=0.0`.

- **Function `create_fre_encoder(state_dim, ...) -> FREEncoder`**: Factory function to instantiate the encoder with custom hyperparameters.

- **Supporting classes** (internal but reusable):  
  - `RewardDiscretizer`: Maps scalar rewards to learned embeddings via uniform binning.  
  - `StateEmbedding`: Linear projection from state_dim to d_model.  
  - `InputSequenceConstructor`: Concatenates state and reward embeddings and projects to d_model.  
  - `PermutationInvariantTransformer`: Standard Transformer encoder without positional encoding or causal mask.  
  - `MeanAggregator`: Mean pooling over the sequence dimension.  
  - `LatentHeads`: Produces μ and log σ² from the aggregated representation.

**Internal Dependencies**  
- Standard library: `math`, `typing` (`Dict`, `Optional`, `Tuple`)  
- External packages:  
  - `numpy` – not used in core logic (only in test)  
  - `torch` – tensor operations  
  - `torch.nn` – neural network modules  
  - `torch.nn.functional` – functional API (not heavily used)  
- No imports from other project files.

**External Dependencies**  
- Expected to be imported by:  
  - `fre/fre_model.py` – to build the full VAE (encoder + decoder)  
  - `fre/trainer.py` – to encode reward functions during IQL training  
  - `fre/evaluator.py` – to produce latent vectors for zero-shot evaluation  
  - `tests/test_encoder.py` – unit tests  
- Key exports used elsewhere: `FREEncoder` class, `create_fre_encoder` function.

**Implementation Notes**  
- **Permutation invariance**: Achieved by omitting positional encodings and using full bidirectional self-attention (no causal mask). The mean pooling over output tokens further ensures order insensitivity.  
- **Reward discretization**: Continuous rewards are clamped to `[r_min, r_max]`, assigned to the nearest of `B` uniform bins, and mapped to a learned embedding. This allows the model to handle continuous scalar rewards without a separate continuous encoder.  
- **VAE design**: The encoder outputs μ and log σ²; the reparameterization trick is used for sampling, and KL divergence is computed analytically against a standard normal prior.  
- **Cross‑file relationships**: The encoder will be paired with a decoder (to be implemented in `fre/decoder.py`) inside `fre/fre_model.py` for joint VAE training. The frozen encoder will later condition the IQL policy and value networks.
