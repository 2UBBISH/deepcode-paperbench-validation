  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    1. REWARD PRIOR DISTRIBUTION (fre/prior.py)
    ============================================================
    Purpose: Generate random unsupervised reward functions η(s) from a mixture of three families.
    Mixture weights: uniform (1/3 each) during training.

    Family 1: Singleton Goal-Reaching Rewards
      - Sample a goal state s_g uniformly from the offline dataset.
      - Reward: η(s) = 0 if ||s - s_g|| < threshold else -1.
      - Threshold: e.g., 0.5 (tuned per environment) or based on goal radius.
      - Implementation: class GoalReachingPrior with sample() returning a callable reward function.

    Family 2: Random Linear Functions
      - Sample a random vector w ~ Uniform(-1, 1) of same dim as state.
      - Apply sparse mask: randomly zero out a fraction (e.g., 80%) of entries to bias towards simple functions.
      - Reward: η(s) = w^T s (dot product).
      - Implementation: class LinearPrior.

    Family 3: Random MLPs
      - Randomly initialize a 2-layer MLP with hidden dim (e.g., 256) and ReLU activations.
      - Input: state; Output: scalar reward.
      - Weights sampled from Kaiming uniform or standard normal.
      - Implementation: class MLPPrior that creates a fresh random network per sample.

    Prior Manager: class MixedPrior that samples uniformly from the three families and returns a reward function object (callable) plus metadata.

    ============================================================
    2. FRE ENCODER (fre/encoder.py)
    ============================================================
    Purpose: Encode a set of (state, reward) pairs into a latent Gaussian distribution p_θ(z | {(s_i, η(s_i))}).
    Architecture: Permutation-invariant Transformer (no positional encoding, no causal mask).

    Input:
      - K encoder states s^e_i sampled uniformly from offline dataset.
      - Corresponding scalar rewards r_i = η(s^e_i).

    Reward Discretization:
      - Discretize continuous reward into B bins (e.g., B=50) based on magnitude.
      - Bin edges: uniform over [r_min, r_max] estimated from prior or fixed range (e.g., [-1, 1]).
      - Each bin has a learned embedding vector of dimension d_reward (e.g., 32).
      - For each reward, find bin index, retrieve embedding.
      - Implementation: class RewardDiscretizer with learnable embedding table.

    State Embedding:
      - Linear projection from state_dim to d_model (e.g., 256).

    Input Sequence Construction:
      - For each of the K pairs: concat(state_embedding, reward_embedding) -> vector of dim d_model + d_reward.
      - Project to d_model via linear layer.
      - Result: K vectors of dim d_model.

    Transformer:
      - Standard Transformer encoder (Vaswani et al. 2017) with:
        - Number of layers: L (e.g., 4)
        - Number of heads: H (e.g., 4)
        - Feedforward dim: d_ff (e.g., 1024)
        - No positional encodings.
        - No causal/autoregressive mask (full bidirectional self-attention).
      - Output: K vectors of dim d_model.

    Aggregation:
      - Average pooling over the K output vectors -> single vector of dim d_model.

    Latent Distribution:
      - Two linear heads from aggregated vector:
        - μ head: Linear(d_model, d_latent) (e.g., d_latent=64)
        - log σ head: Linear(d_model, d_latent)
      - Latent z sampled via reparameterization: z = μ + σ * ε, ε ~ N(0, I).

    ============================================================
    3. FRE DECODER (fre/decoder.py)
    ============================================================
    Purpose: Predict reward for a given state conditioned on latent z: q_θ(η(s) | s, z).
    Architecture: Feedforward neural network.

    Input:
      - State s (single state, not a set).
      - Latent vector z.

    Network:
      - Concatenate [s, z] -> input vector.
      - MLP: 2-3 hidden layers (e.g., [256, 256]) with ReLU activations.
      - Output: scalar predicted reward.

    Training:
      - For a batch of decoding states {s^d_j} (different from encoder states), predict rewards.
      - Loss: MSE between predicted rewards and true rewards η(s^d_j).
      - Combined with KL divergence from encoder for VAE training.

    ============================================================
    4. FULL FRE MODEL (fre/fre_model.py)
    ============================================================
    Purpose: Joint training of encoder and decoder as a VAE.
    Loss function (Equation 6, inferred):
      L_FRE = (1/K') Σ_j (η(s^d_j) - q_θ(s^d_j, z))^2 + β * D_KL(p_θ(z | {(s^e_i, η(s^e_i))}) || N(0, I))
      where β is a hyperparameter (e.g., 0.1 or 1.0).

    Training loop (Algorithm 1, encoder phase):
      while not converged:
        Sample reward function η ~ p(η)
        Sample K encoder states {s^e} ~ D
        Sample K' decoder states {s^d} ~ D (K' can be same as K or larger, e.g., 128)
        Compute rewards for both sets using η
        Forward pass: encoder -> z; decoder -> predicted rewards for decoder states
        Compute loss, backprop, update encoder and decoder parameters.

    ============================================================
    5. OFFLINE RL WITH IQL (fre/iql.py, fre/policy.py)
    ============================================================
    Purpose: Train a policy π(a|s,z), Q-function Q(s,a,z), and value function V(s,z) conditioned on latent z using Implicit Q-Learning (Kostrikov et al., 2021).

    Networks:
      - Policy π(a|s,z): Gaussian policy for continuous actions.
        - Input: concat(s, z) -> MLP -> mean and log_std.
        - For discrete actions: softmax over actions.
      - Q-function: Q(s,a,z) -> MLP with input concat(s, a, z) -> scalar Q-value.
      - Value function: V(s,z) -> MLP with input concat(s, z) -> scalar value.

    IQL Losses:
      - Value loss: L_V = E[(τ - Q(s,a,z))^2] where τ is expectile (e.g., 0.7-0.9).
        Actually IQL uses expectile regression: L_V = E[ L2_τ(Q(s,a,z) - V(s,z)) ] where L2_τ(u) = |τ - 1(u<0)| * u^2.
      - Q loss: L_Q = E[(r + γ V(s',z) - Q(s,a,z))^2] (standard TD learning, but with V instead of max Q).
      - Policy loss: L_π = E[ exp( (Q(s,a,z) - V(s,z)) / temperature ) * log π(a|s,z) ] (advantage-weighted regression, AWR).
        Temperature α (e.g., 3.0).

    Training loop (Algorithm 1, policy phase):
      while not converged:
        Sample reward function η ~ p(η)
        Sample K encoder states {s^e} ~ D
        Encode into z using frozen FRE encoder (no gradient).
        Sample batch of (s, a, r=η(s), s') from D.
        Update V, Q, π using IQL losses with z as conditioning.

    Strided Training (fre/trainer.py):
      Phase 1: Train only FRE encoder+decoder until convergence (e.g., fixed number of steps or loss plateau).
      Phase 2: Freeze encoder, train IQL networks using encoder outputs.

    ============================================================
    6. DATA LOADING (fre/dataset.py)
    ============================================================
    - Support D4RL datasets (AntMaze, Kitchen) via d4rl library.
    - Support ExORL datasets (walker, cheetah) via custom loading or provided files.
    - Normalize states (mean 0, std 1) based on dataset statistics.
    - Provide sampling methods: sample random states, sample trajectories, sample state-action pairs.

    ============================================================
    7. EVALUATION (fre/evaluator.py)
    ============================================================
    Zero-shot evaluation:
      - For a given downstream task (reward function η_test):
        - Sample K=32 encoder states from dataset (or environment).
        - Compute rewards, encode to z using trained FRE encoder.
        - Run policy π(a|s,z) in environment for 20 episodes.
        - Compute average return.
      - Normalize returns between 0 and 100 using min and max reference returns (e.g., random policy = 0, expert = 100, or based on dataset max return).
      - Repeat for 5 random seeds.

    ============================================================
    8. HYPERPARAMETERS (configs/default.yaml)
    ============================================================
    Key hyperparameters (to be tuned per domain):
      - K encoder states: 32
      - K' decoder states: 128
      - Reward bins B: 50
      - d_model: 256
      - d_reward_embed: 32
      - d_latent: 64
      - Transformer layers L: 4, heads H: 4, d_ff: 1024
      - Decoder MLP: [256, 256]
      - VAE β: 0.1
      - IQL expectile τ: 0.7 (AntMaze), 0.9 (ExORL)
      - IQL temperature α: 3.0
      - Discount γ: 0.99
      - Batch size: 256 (FRE), 256 (IQL)
      - Learning rate: 1e-4 (FRE), 3e-4 (IQL)
      - Optimizer: Adam
      - FRE training steps: 100k
      - IQL training steps: 1M
      - Prior mixture: uniform (1/3 each)
