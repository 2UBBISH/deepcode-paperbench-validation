    # CORE COMPONENTS

    1. OFFLINE DATA LOADING
       File: fre/data_utils.py + fre/env_utils.py
       - AntMaze: D4RL `antmaze-large-diverse-v2`, states ~29-dim, actions 8-dim.
       - Kitchen: D4RL `kitchen-complete-v0` or `kitchen-partial-v0`.
       - ExORL: DeepMind Control `walker_walk` and `cheetah_run` offline datasets from ExORL.
       - Each dataset returns dict of `observations`, `actions`, `next_observations`,
         `rewards`, `terminals`/`timeouts`. We treat terminal and timeout separately for
         AntMaze to avoid bootstrap through episode boundaries.

    2. RANDOM PRIOR REWARD DISTRIBUTION
       File: fre/reward_priors.py
       The prior p(eta) is an equal mixture of three function families.
       At each call `sample_reward(domain, env_state_dim)`, randomly select:
       (a) Singleton/goal-reaching reward:
           - Sample a goal state g from the offline dataset.
           - eta(s) = -1.0 if ||s - g||_2 > epsilon else 0.0.
           - epsilon domain-specific: AntMaze/Kitchen ~2.0, ExORL ~0.03.
       (b) Random linear function:
           - Sample w ~ Uniform(-1, 1) elementwise, then apply a Bernoulli mask
             with keep probability 0.25 to make it sparse.
           - eta(s) = w^T s.
       (c) Random MLP function:
           - Instantiate a small untrained 2-layer MLP:
             Linear(state_dim, 128) -> ReLU -> Linear(128, 1).
           - Use its forward output as eta(s). Weights are redrawn every time.

    3. REWARD DISCRETIZATION / EMBEDDING
       File: fre/reward_tokenizer.py
       Reward values are converted to a learned categorical embedding.
       - Use B = 64 bins uniformly covering [-R_clip, R_clip], default R_clip = 10.0.
       - `token = digitize(clip(eta(s), -R_clip, R_clip), bin_edges)`.
       - Learned embedding table `Embedding(B, embed_dim)`, default embed_dim = 64.
       - During training, the embedding is learned jointly with the encoder/decoder.

    4. FRE ENCODER: PERMUTATION-INVARIANT TRANSFORMER VAE
       File: fre/fre_encoder.py
       Input context: `C = {(s_i^e, eta(s_i^e))}_{i=1..K}`, with K = 32
       for both training and evaluation.
       Token construction:
         h_i^0 = LayerNorm( Linear_state(s_i) + RewardEmbedding(bin(eta(s_i))) )
       Transformer encoder:
         - 2 layers
         - hidden_dim = 256
         - 4 attention heads
         - feedforward hidden = 512
         - no positional encodings
         - no causal mask: full bidirectional attention treats inputs as an unordered set.
       Aggregate:
         h_mean = mean_i(h_i^L)
         z_mean = Linear_mean(h_mean)
         z_logvar = Linear_logvar(h_mean)
         z_std = exp(0.5 * z_logvar)
       Reparameterize: z = z_mean + z_std * epsilon, epsilon ~ N(0,I).
       Latent dimension default = 256.

    5. FRE DECODER
       File: fre/fre_decoder.py
       q_theta(eta(s)|s,z) is a feedforward network:
         Linear(state_dim + latent_dim, 256) -> ReLU -> Linear(256, 1)
       Decoder states `s_i^d` are sampled independently from the offline dataset.
       Default K' = 256 decoder states per VAE batch.

    6. FRE VAE OBJECTIVE
       File: fre/fre_vae.py
       Objective, approximating Equation (6):
         L_FRE = (1/K') * sum_i (q_theta(s_i^d,z) - eta(s_i^d))^2
                 + beta_kl * KL( N(z_mean, z_std) || N(0,I) )
       Default beta_kl = 1.0, but configurable.
       Optimizer: Adam, learning rate 3e-4, batch size 256 contexts.
       Stop when reconstruction MSE on held-out sampled contexts stops improving
       for 50 evaluation steps, or after 200k total VAE gradient steps.

    7. FROZEN-ENCODER IQL POLICY TRAINING
       File: fre/iql.py, fre/agent.py, fre/trainer_iql.py
       Conditioned on z, all networks are MLPs:
         Q_phi(s,a,z): state+action+z -> scalar; two Q networks with target copies.
         V_psi(s,z): state+z -> scalar.
         pi_omega(a|s,z): state+z -> Gaussian action distribution with Tanh squashing;
           for evaluation take the mean.
       IQL losses:
         L_V = E_{(s,a)~D,z~p|C}[ L2^tau( Q_phi_target(s,a,z) - V_psi(s,z) ) ]
         L_Q = E[( r + gamma * V_psi(s',z) - Q_phi(s,a,z) )^2]
         L_pi = E[ exp((Q_phi(s,a,z) - V_psi(s,z)) / temperature)
                   * MSE(pi_omega(s,z), a) ]
       Recommended IQL hyperparameters:
         gamma = 0.99
         expectile tau = 0.7
         advantage temperature = 3.0
         soft target update tau = 0.005
         Adam lr = 3e-4
       During policy training, at every step:
         - Sample eta ~ p(eta)
         - Sample K = 32 encoding states from D
         - Compute context tokens, encode with frozen encoder to obtain z
         - Sample a batch of transitions from D
         - Compute reward r = eta(s)
         - Apply IQL updates.
       Training runs for 1M gradient steps (typical); keep encoder completely frozen.

    8. ZERO-SHOT EVALUATION TASKS
       File: fre/evaluator.py
       AntMaze tasks:
         - goal-reaching: reward -1 until distance to goal < epsilon, else 0
         - directional: eta(s) = (x(s)-x0)*cos(theta)+(y(s)-y0)*sin(theta)
         - random-simplex: procedural noise function over XY positions
         - path-loop, path-edges, path-center: hand-designed indicator/path rewards
       ExORL tasks:
         - goal-reaching to states sampled from dataset
         - forward/backward velocity from DMC state features
       Kitchen tasks:
         - one reward per each of the 7 D4RL subtasks.
       For each task, sample K=32 state-reward pairs, encode z, and roll out
       the deterministic policy. Normalize returns between 0 and 100 using
       task-specific min/max reference returns.
       Report mean and standard deviation over 20 episodes and 5 training seeds.

    9. BASELINE COMPARISON METHODS REQUIRED BY TABLE 1 AND TABLE 2
       Directory: baselines/
       All methods are evaluated with the same downstream tasks as FRE.
       Use 5120 reward samples at evaluation time for FB and SF, as in the paper.
       FRE uses only 32 samples.

       (a) GC-IQL: Goal-Conditioned IQL
           File: baselines/gc_iql.py
           - IQL with goal concatenated into state/observation.
           - Use hindsight relabeling: relabel sampled transitions with future goals
             from the same trajectory.
           - Train V, double Q, and advantage-weighted policy exactly like FRE IQL,
             but condition on goal rather than learned z.

       (b) GC-BC: Goal-Conditioned Behavioral Cloning
           File: baselines/gc_bc.py
           - Behavioral cloning policy conditioned on state + goal.
           - Relabel dataset transitions with future goals and train policy to
             imitate the corresponding action under a mean-squared error loss.

       (c) OPAL
           File: baselines/opal.py
           - Offline skill discovery baseline.
           - Train a trajectory-chunk VAE to learn a latent skill space.
           - Use a behavioral cloning policy conditioned on the learned skill.
           - Paper uses a privileged evaluation: roll out 10 candidate skills online,
             score them on the downstream task, and report the best skill's score.

       (d) FB: Forward-Backward representations
           File: baselines/fb.py
           - Use upstream code from Touati et al. 2022 if available.
           - Otherwise implement the FB successor-measure objective:
             learn forward F(s,a,z) and backward B(s,z) representations with
             F(s,a,z)^T B(s',z) approximating successor measures.
           - At test time, perform linear regression from sampled state-reward pairs
             to produce the task vector z and then execute the induced policy.
           - Use 5120 reward samples during test-time adaptation.

       (e) SF: Successor Features with ICM features
           File: baselines/sf.py
           - Use upstream code or implement successor features.
           - Learn features with ICM as in Touati et al. 2022.
           - Train successor features and a policy over the learned feature space.
           - At test time, use 5120 reward samples to fit the task vector under
             the linear reward model.

    10. EXPERIMENT: ZERO-SHOT TRANSFER AND DECODER VISUALIZATION (Section 5.1 / Figure 3)

         and Kitchen subtasks.
       - Generate Table 1 normalized scores.

    12. EXPERIMENT: REWARD-FAMILY SCALING PROPERTIES (Section 5.3 / Figure 5, Table 4)
       File: scripts/run_scaling_experiment.py
       - Train FRE agents on every nonempty subset of the three prior reward families:
           {goals}, {linear}, {mlp}, {goals,linear}, {goals,mlp}, {linear,mlp},
           {goals,linear,mlp} = FRE-all.
       - Keep total training budget identical across agents; FRE-all receives
         one-third as many samples from each family as the single-family agents.
       - Evaluate all downstream tasks for every agent.
       - Expected result: FRE-all displays the largest total score and remains
         competitive across tasks, demonstrating smooth scaling with reward diversity.

    13. EXPERIMENT: PRIOR DOMAIN KNOWLEDGE AUGMENTATION (Section 5.4 / Figure 6)
       File: scripts/run_domain_knowledge_experiment.py

         e.g. functions depending only on XY position or velocity.
       - Use exactly the same FRE encoder, decoder, and RL architecture; the only
         change is the prior reward distribution.
       - Evaluate on targeted downstream tasks aligned with the augmented prior.
       - Expected result: task-specific prior improves corresponding task performance
         without any algorithmic or architectural modifications.

      - Assert decoder MSE decreases from initial value and latent z

    Stage 3: IQL smoke test.
      - Use a small D4RL dataset such as `halfcheetah-medium-v2` and a

      - Confirm value loss and policy loss decrease; no NaN gradients.
      - Confirm frozen encoder outputs remain unchanged during policy training.
