  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    COMPONENT 1: Prior Reward Distribution (rewards/)
    ============================================================
    Purpose: Generate diverse random unsupervised reward functions for training the FRE encoder and RL agent.
    Details:
      - Mixture of three function families with equal probability (uniform mixture):
        a) Singleton (Goal-reaching): reward = -1 for every timestep where goal not reached, 0 otherwise.
           Goals are sampled uniformly from the offline dataset states.
        b) Random Linear: reward(s) = dot(w, s) where w ~ Uniform(-1,1) with a sparse mask (e.g., 80% zeros) to bias towards simple functions.
        c) Random MLP: 2-layer MLP with random weights (no training). Architecture: Linear(in_dim, 256) -> ReLU -> Linear(256, 1). Weights initialized via Kaiming uniform.
      - Each reward function is callable: takes a batch of states and returns scalar rewards.
      - Implementation: base.py defines abstract class; singleton.py, linear.py, mlp.py implement specific families; mixture.py samples uniformly from the three.

    ============================================================
    COMPONENT 2: Reward Embedding (models/reward_embedding.py)
    ============================================================
    Purpose: Discretize scalar rewards into a learned embedding token space for transformer input.
    Details:
      - Discretize reward magnitude into B bins (e.g., B=64) covering the range of observed rewards.
      - Learn an embedding table of size (B, d_embed) where d_embed matches state feature dimension.
      - For each reward value, find bin index, then lookup embedding.
      - If reward range unknown, use adaptive binning based on min/max of batch.

    ============================================================
    COMPONENT 3: FRE Encoder (models/fre_encoder.py)
    ============================================================
    Purpose: Encode a set of (state, reward) pairs into a latent Gaussian distribution pθ(z | {(s_i, η(s_i))}).
    Architecture:
      - Input: K states (each dim d_state) and K corresponding reward embeddings (dim d_embed).
        Concatenate each state with its reward embedding -> K vectors of dim (d_state + d_embed).
      - Permutation-invariant Transformer (no positional encodings, no causal masking):
        * Hyperparameters: num_layers=3, num_heads=4, hidden_dim=256, dropout=0.1 (reasonable defaults; paper does not specify).
        * Treat the K vectors as an unordered set (tokens).
        * Apply self-attention across all tokens.
      - Output: Average pooling over the final layer token representations -> single vector h of dim hidden_dim.
      - Two linear projection heads from h:
        * μ = Linear(hidden_dim, latent_dim)
        * log σ = Linear(hidden_dim, latent_dim)
      - Latent z is sampled via reparameterization: z = μ + ε * exp(log σ), ε ~ N(0,I).
      - latent_dim: e.g., 64 or 128.
    Key formulas:
      - pθ(z | {(s_i, r_i)}) = N(z; μ, diag(σ²))
      - Encoder training maximizes ELBO (Equation 6 in paper): 
        L_encoder = E_{η~p(η)} [ E_{z~pθ}[ Σ_{s^d} log qθ(η(s^d)|s^d, z) ] - KL(pθ(z|·) || p(z)) ]
        where p(z) is standard normal prior, and qθ is the decoder.
      - In practice, minimize MSE between predicted and true rewards under decoding states (the reconstruction term), plus a small KL penalty (β-VAE style, β e.g., 0.1).

    ============================================================
    COMPONENT 4: FRE Decoder (models/fre_decoder.py)
    ============================================================
    Purpose: Predict reward η(s) for a state s given latent encoding z.
    Architecture:
      - Feedforward neural network: input = concatenate(s, z) -> Linear -> ReLU -> Linear -> ReLU -> Linear -> scalar output.
      - Hidden layers: [256, 256] (reasonable default).
      - Trained jointly with encoder to minimize MSE: L_decoder = (1/K') Σ_{k} (η(s_k^d) - qθ(s_k^d, z))².
    Note: Decoding states {s_k^d} are different from encoding states {s_k^e}; both sampled from offline dataset.

    ============================================================
    COMPONENT 5: IQL Agent (models/iql_agent.py)
    ============================================================
    Purpose: Offline RL agent conditioned on latent z, using Implicit Q-Learning (Kostrikov et al., 2021).
    Networks (all take state s and latent z as input):
      - Q-function: Q(s, a, z) -> scalar. Architecture: MLP with hidden [256, 256].
      - Value function: V(s, z) -> scalar. Architecture: MLP with hidden [256, 256].
      - Policy: π(a|s, z) -> Gaussian distribution over actions. Architecture: MLP with hidden [256, 256], outputs mean and log_std.
    IQL Losses:
      - Value loss (expectile regression): 
        L_V = E_{(s,a)~D} [ L2_τ( Q_target(s,a,z) - V(s,z) ) ]
        where L2_τ(u) = |τ - 1(u<0)| * u², τ is expectile (e.g., 0.7).
      - Q loss (standard TD with target V):
        L_Q = E_{(s,a,r,s')~D} [ (r + γ V_target(s',z) - Q(s,a,z))² ]
      - Policy loss (advantage-weighted regression):
        L_π = E_{(s,a)~D} [ exp(β * (Q(s,a,z) - V(s,z))) * log π(a|s,z) ]
        where β is temperature (e.g., 3.0).
    - Target networks for Q and V updated via Polyak averaging (τ=0.005).
    - All networks conditioned on z by concatenating z to state (and action for Q) before MLP.

    ============================================================
    COMPONENT 6: Training Loop (training/)
    ============================================================
    Purpose: Implement Algorithm 1 from paper with strided training scheme.
    Phase 1: Train FRE encoder only (train_encoder.py)
      - While not converged:
        * Sample reward function η ~ p(η) (mixture).
        * Sample K encoding states {s_k^e} ~ D (uniformly from offline dataset).
        * Sample K' decoding states {s_k^d} ~ D (different from encoding states).
        * Compute rewards r_k^e = η(s_k^e), r_k^d = η(s_k^d).
        * Encode: z ~ pθ(· | {(s_k^e, r_k^e)}).
        * Decode: predict r̂_k^d = qθ(s_k^d, z).
        * Loss = MSE(r̂_k^d, r_k^d) + β * KL( pθ(z|·) || N(0,I) ).
        * Update encoder and decoder parameters via gradient descent.
      - Convergence criterion: loss plateaus or max iterations reached.
    Phase 2: Train RL with frozen encoder (train_rl.py)
      - Freeze encoder parameters.
      - While not converged:
        * Sample reward function η ~ p(η).
        * Sample K encoding states {s_k^e} ~ D, compute rewards, encode to z.
        * Sample batch of (s, a, r=η(s), s') from D.
        * Update Q, V, π using IQL losses with z as conditioning.
      - Note: The same η is used for encoding and for computing rewards in the batch.
    Orchestrator (trainer.py): Run Phase 1 for N_enc steps, then Phase 2 for N_rl steps. Save checkpoints.

    ============================================================
    COMPONENT 7: Data Loading (data/)
    ============================================================
    Purpose: Load offline datasets from D4RL and ExORL benchmarks.
    Datasets:
      - AntMaze: antmaze-large-diverse-v2 (D4RL).
      - Kitchen: kitchen-complete-v0 (D4RL) or similar; paper uses 7 subtasks.
      - ExORL: walker and cheetah domains from ExORL benchmark (Yarats et al., 2022). Need to download or use provided data.
    Implementation:
      - Use D4RL library for AntMaze and Kitchen.
      - For ExORL, use the dataset provided by the benchmark (e.g., from FB paper repo).
      - Replay buffer: stores (state, action, next_state, terminal) tuples; rewards are computed on-the-fly by sampled η.
      - Normalize states to mean 0, std 1 based on dataset statistics.

    ============================================================
    COMPONENT 8: Evaluation (evaluation/)
    ============================================================
    Purpose: Zero-shot evaluation on downstream tasks.
    Procedure:
      - For each test task (e.g., goal-reaching, directional, etc.):
        * Define the true reward function η_test (not seen during training).
        * Sample K=32 encoding states from the dataset (or from environment rollouts? Paper says "from the offline dataset").
        * Compute rewards on these states using η_test.
        * Encode to z using trained FRE encoder.
        * Run policy π(a|s, z) in the environment for 20 episodes, compute average return.
        * Normalize returns between 0 and 100 based on min/max possible returns (or as per benchmark standard).
      - Tasks per domain:
        * AntMaze: goal-reaching (random goals), directional (move in (x,y) direction), random-simplex (procedural noise), path tasks (edges, loop, center).
        * ExORL Walker/Cheetah: goal-reaching (random goals), velocity (forward/backward).
        * Kitchen: 7 subtasks (microwave, light, etc.).
      - Metrics: mean and std over 5 random seeds, each evaluated over 20 episodes.

    ============================================================
    COMPONENT 9: Configuration (configs/)
    ============================================================
    Purpose: Centralize all hyperparameters.
    Key hyperparameters (with reasonable defaults inferred from paper and typical IQL/FRE settings):
      - K (encoding states): 32 (evaluation), 64 (training) – paper uses 32 for eval, training K not specified; we set 64.
      - K' (decoding states): 64.
      - latent_dim: 64.
      - Transformer: layers=3, heads=4, hidden=256, dropout=0.1.
      - Reward embedding bins: 64.
      - Decoder MLP: [256, 256].
      - IQL: τ (expectile)=0.7, β (temperature)=3.0, γ=0.99, target τ=0.005.
      - Optimizer: Adam, lr=3e-4 for all networks.
      - Batch size: 256 for RL, 128 for encoder.
      - Phase 1 steps: 100k (or until convergence).
      - Phase 2 steps: 1M.
      - KL penalty β: 0.1.
