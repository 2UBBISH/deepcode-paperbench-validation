    1. Pre-trained policy repository
       - File: training/pretrain_ppo.py, training/pretrain_sac.py
       - Train PPO agents for MuJoCo (Hopper-v3, Walker2d-v3, Reacher-v2, HalfCheetah-v3)

       - Train a SAC agent for Experiment IV on Hopper, then use GAIL (imitation library)
         to learn a PPO-style approximated policy from SAC rollouts.

    2. Mask network (simplified StateMask) — Algorithm 1
       - File: rice/mask_network.py
       - Inputs: target policy π, environment env
       - Output: binary mask policy ˜πθ(a^m | s) where a^m ∈ {0,1}
       - Action blending:
           a_t ⊙ a_t^m = { a_t               if a_t^m = 0
                           { a_random        if a_t^m = 1
         For continuous actions sample a_random ~ Uniform(action_space.low, action_space.high);
         for discrete actions sample uniformly over |A|.
       - Reward reformulation (Theorem 3.3): under Assumption 3.1, η(¯π) ≤ η(π), so
         maximize J(θ) = η(¯π) with augmented reward
           R'(s_t,a_t) = R(s_t,a_t) + α · a_t^m
         where α is the blinding-bonus hyper-parameter.
       - Training loop:
         (a) Initialize θ and θ_old ← θ.
         (b) For each iteration:
             - Sample s0 ~ ρ.
             - Rollout T steps: a_t ~ π(·|s_t), a_t^m ~ ˜πθ_old(·|s_t),
               execute blended action, store (s_t, s_{t+1}, a_t^m, R'_t).
             - Update θ_old ← θ with PPO on the collected buffer.
       - Default α = 0.0001 (Table 3); sensitivity sweep {0.01, 0.001, 0.0001}.

    3. Critical-state identification and mixed initial distribution
       - File: rice/mixed_reset_env.py, rice/utils.py
       - Given π and ˜π, sample one trajectory τ of length K (typically full episode)
         by running π.
       - Compute importance score ξ(s_t) = ˜π(a^m=0 | s_t) for every state.
       - Select the single most critical state s* = argmax_t ξ(s_t).
       - Reset distribution implementation: with probability p (per episode) set
         s0 = s* via env.set_state / state-vector injection; otherwise s0 ~ ρ.
         This realizes the mixture μ(s) = p · d_ρ^ˆπ(s) + (1-p) · ρ(s).
       - Default p per task from Table 3 (0.25 or 0.50); sensitivity sweep
         {0, 0.25, 0.5, 0.75, 1}.

    4. RND exploration bonus
       - File: rice/rnd_module.py
       - Fixed random target network f(s) and trainable predictor network ˆf(s).
       - Intrinsic reward:
           R_t^RND = || f(s_{t+1}) − ˆf(s_{t+1}) ||^2
       - Normalize R_t^RND with running mean and standard deviation.
       - Augmented policy reward:
           R'(s_t,a_t) = R(s_t,a_t) + λ · R_t^RND
       - Update ˆf with Adam on MSE loss at each PPO update.
       - Default λ per task from Table 3 (0.001 or 0.01); sensitivity sweep
         {0, 0.1, 0.01, 0.001}.

    5. RICE refining loop — Algorithm 2
       - File: rice/refine_agent.py, training/train_rice.py
       - Inputs: pre-trained π, mask ˜π, default ρ, reset probability p, RND weight λ
       - For each iteration:
         (a) With probability p roll-in π to obtain τ, pick critical state s*, set s0 = s*;
             else sample s0 ~ ρ.
         (b) Rollout T steps with current policy πθ, collecting
             (s_t, s_{t+1}, a_t, R_t + λ·R_t^RND).
         (c) Optimize πθ with PPO loss on D.
         (d) Optimize RND predictor ˆf with MSE on D.
       - Stop when evaluation reward plateaus; report mean/std over 3 seeds.

    6. Baseline refiners
       - PPO fine-tuning: continue PPO with reduced learning rate, no mixed reset, λ=0.
       - StateMask-R: always reset to the single most critical state (p=1), λ=0.
       - JSRL: guide-policy curriculum; start all steps from π_g and progressively
         reduce guided prefix length while training π_e with PPO.
       - Random explanation: replace mask-net critical-state selection with a uniform
         random visited state, then run RICE with p and λ.
       - SIL (Self-Imitation Learning): prioritize past successful trajectories in replay.

    7. Fidelity evaluation (Experiment I)
       - File: evaluation/fidelity.py
       - For each trajectory of length L, slide a window of length l and compute the
         average importance score in the window.
       - Select the window with highest average score, randomize actions in that window,
         complete the episode with π, and measure reward change d.
       - Fidelity score = log(d / d_max) − log(l / L).
       - Report for top-K% windows K ∈ {10,20,30,40} over 500 trajectories.

    8. Real-world environment adapters
       - Selfish mining: wrap github.com/roibarzur/pto-selfish-mining PPO agent.
       - CAGE Challenge 2: wrap github.com/john-cardiff/-cyborg-cage-2 champion PPO
         blue agent; reward is sum over trail lengths {30,50,100}.
       - Autonomous driving: MetaDrive Macro-v1 via DI-drive; BEV state vector,
         2-D continuous action → steering/acceleration/brake.
       - Malware mutation: MalConv gym from github.com/bfilar/malware_rl; 16 discrete
         mutation actions, reward = 10 on evasion else sc0 − sc_t.
