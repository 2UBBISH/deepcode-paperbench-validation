  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    COMPONENT 1: Offline Dataset Handling (data/dataset.py)
    ============================================================
    - Load standard offline RL datasets:
      * AntMaze: D4RL 'antmaze-large-diverse-v2'
      * ExORL: Walker and Cheetah from ExORL benchmark (DeepMind Control Suite)
      * Kitchen: D4RL 'kitchen-complete-v0' (or appropriate multi-task variant)
    - Provide a replay buffer that stores (state, action, next_state, done) tuples.
    - For encoder training, only states are needed; for IQL, full transitions.
    - Support sampling of K states uniformly from the entire dataset for encoder/decoder.
    - Support sampling of batches for IQL training.

    ============================================================
    COMPONENT 2: Prior Reward Distribution (reward_functions/)
    ============================================================
    Three random unsupervised reward function families, mixed uniformly:

    a) Singleton Goal-Reaching (singleton.py):
       - Sample a goal state g uniformly from the dataset.
       - Reward: r(s) = 0 if ||s - g||_2 < epsilon else -1.
       - epsilon: task-dependent threshold (e.g., 0.5 for AntMaze, 0.1 for ExORL).
       - For Kitchen, goal-reaching may use achieved subtask indicators; alternatively,
         use state distance on a subset of dimensions (e.g., object positions).

    b) Random Linear Functions (linear.py):
       - Sample a weight vector w ~ Uniform(-1, 1) of same dimensionality as state.
       - Apply sparse mask: randomly zero out a fraction (e.g., 80%) of w entries
         to bias towards simple functions.
       - Reward: r(s) = dot(w, s).

    c) Random MLPs (mlp.py):
       - Initialize a 2-layer MLP with random weights (e.g., Xavier uniform).
       - Hidden size: 256, activation: ReLU.
       - Input: state, output: scalar reward.
       - The network is fixed (not trained); it acts as a random nonlinear function.

    Mixture (mixture.py):
       - Uniformly sample one of the three types with probability 1/3 each.
       - Provides a callable reward function r = eta(s).

    ============================================================
    COMPONENT 3: FRE Encoder (models/encoder.py)
    ============================================================
    Architecture: Permutation-invariant transformer VAE.

    Input: K state-reward pairs {(s_k, r_k)}_{k=1..K}.
    Processing:
      1. Reward discretization: Map scalar reward r_k to a bin index.
         - Use a fixed number of bins (e.g., 64) over a clipped range [-R_max, R_max].
         - R_max can be set per domain or adaptively normalized.
         - Learn an embedding table E_reward of size (num_bins, d_embed).
         - For each r_k, compute bin_idx = clamp(round((r_k + R_max)/(2*R_max) * num_bins), 0, num_bins-1).
         - Get reward embedding e_k = E_reward[bin_idx].
      2. Token construction: Concatenate state s_k and reward embedding e_k.
         - If state dim != d_embed, project state to d_embed via a learned linear layer.
         - Token: t_k = [Linear(s_k); e_k]  (dimension 2*d_embed).
      3. Transformer encoder:
         - No positional encodings, no causal masking (inputs treated as unordered set).
         - Number of layers: 2-4, hidden size: 256, heads: 4.
         - Output: set of K vectors of dimension d_model.
      4. Aggregation: Average the K output vectors to get a single vector h.
      5. VAE latent projection:
         - mu = Linear(h)  (dimension d_latent, e.g., 64)
         - logvar = Linear(h) (dimension d_latent)
         - Sample z = mu + eps * exp(0.5 * logvar), eps ~ N(0, I).

    ============================================================
    COMPONENT 4: FRE Decoder (models/decoder.py)
    ============================================================
    - Feedforward neural network: input = [s; z] (concatenated), output = scalar predicted reward.
    - Architecture: 2-3 hidden layers, 256 units each, ReLU activation.
    - Trained jointly with encoder to minimize MSE between predicted and true rewards
      on a separate set of decoder states (K' states, different from encoder states).

    ============================================================
    COMPONENT 5: VAE Training Objective (training/train_encoder.py)
    ============================================================
    Loss function (Equation 6 in paper, standard beta-VAE ELBO):
      L = (1/K') * sum_{k=1}^{K'} (r_k - decoder(s_k, z))^2
          + beta * KL( N(mu, sigma^2) || N(0, I) )
    where:
      - r_k are true rewards for decoder states under sampled eta.
      - z is sampled from encoder given encoder states and their rewards.
      - beta is a weighting factor (e.g., 1.0 or smaller like 0.1).
      - KL divergence: 0.5 * sum(1 + logvar - mu^2 - exp(logvar)).

    Training procedure (Phase 1):
      - For each iteration:
        1. Sample reward function eta ~ p(eta) (mixture).
        2. Sample K encoder states {s^e} from dataset.
        3. Compute rewards r^e = eta(s^e).
        4. Sample K' decoder states {s^d} from dataset (disjoint from encoder states).
        5. Compute rewards r^d = eta(s^d).
        6. Forward encoder to get mu, logvar, sample z.
        7. Forward decoder on (s^d, z) to get predicted rewards.
        8. Compute loss and update encoder+decoder parameters.
      - Train until convergence (e.g., validation loss plateaus).

    ============================================================
    COMPONENT 6: IQL Networks (models/iql.py)
    ============================================================
    All networks conditioned on latent z by concatenating z to inputs.

    a) Q-function (critic): Q(s, a, z) -> scalar.
       - Input: [s; a; z], output: scalar Q-value.
       - MLP: 3 hidden layers, 256 units, ReLU.
       - Two Q-networks (double Q-learning) with target networks.

    b) Value function: V(s, z) -> scalar.
       - Input: [s; z], output: scalar V-value.
       - MLP: 3 hidden layers, 256 units, ReLU.

    c) Policy (actor): pi(a|s, z).
       - Input: [s; z], output: mean and log_std of Gaussian distribution over actions.
       - MLP: 3 hidden layers, 256 units, ReLU.
       - Action space: continuous, bounded (tanh squashing).

    ============================================================
    COMPONENT 7: IQL Training (training/train_iql.py)
    ============================================================
    Algorithm: Implicit Q-Learning (Kostrikov et al., 2021) adapted for z-conditioning.

    Hyperparameters:
      - Expectile tau: 0.7 (for V expectile regression)
      - Temperature beta: 3.0 (for advantage-weighted policy update)
      - Discount gamma: 0.99
      - Soft target update rate: 0.005
      - Learning rate: 3e-4 (Adam)

    Training step (Phase 2, encoder frozen):
      1. Sample batch of transitions (s, a, s') from offline dataset.
      2. Sample reward function eta ~ p(eta).
      3. Sample K encoder states, compute rewards, encode to get z (sample from encoder).
         (Alternatively, use the same eta for the whole batch? The paper says:
         "At each training iteration, a batch of state-action pairs are selected...
         Additionally, a batch of reward functions eta are also sampled...
         Each reward function is evaluated on K encoding states... produce z."
         So we can sample one eta per batch, or one per transition. We'll sample one eta
         per batch and use its z for all transitions in the batch, as typical.)
      4. Compute rewards for the batch: r = eta(s), r' = eta(s') (for next state).
      5. IQL losses:
         a) Value loss (expectile regression):
            L_V = E_{(s,a)}[ L2_tau( Q_target(s,a,z) - V(s,z) ) ]
            where L2_tau(u) = |tau - 1(u<0)| * u^2.
            Use target Q (min of two target Q networks).
         b) Q loss:
            L_Q = E_{(s,a,s')}[ ( r + gamma * V(s',z) - Q(s,a,z) )^2 ]
            (use both Q networks, with target V).
         c) Policy loss (advantage-weighted regression):
            A(s,a,z) = Q(s,a,z) - V(s,z)
            weights = exp( A(s,a,z) * beta ), clipped to max_weight (e.g., 100).
            L_pi = - E[ weights * log pi(a|s,z) ]  (or equivalently weighted MSE
            if using deterministic policy; for Gaussian, negative log-likelihood).
      6. Update all networks (except target networks soft-updated).
      7. Repeat for many iterations.

    Strided training scheme:
      - Phase 1: Train only encoder+decoder (FRE) until convergence.
      - Phase 2: Freeze encoder, train IQL networks from scratch.

    ============================================================
    COMPONENT 8: Zero-Shot Evaluation (evaluation/evaluate.py)
    ============================================================
    For a given downstream task (e.g., ant-goal-reaching, exorl-walker-velocity):
      1. Define the evaluation reward function eta_eval (from eval_rewards.py).
      2. Sample K=32 states from the offline dataset (or from environment rollouts?
         The paper says "FRE utilizes only 32 examples of (state, reward) pairs during evaluation".
         These states can be sampled from the dataset or from the environment.
         We'll sample from the dataset as in the paper.)
      3. Compute rewards on these states using eta_eval.
      4. Encode using the frozen encoder to get z (use mu, no sampling for deterministic eval).
      5. Run the policy pi(a|s, z) in the environment for N episodes (e.g., 20).
      6. Compute average return (undiscounted sum of eta_eval rewards).
      7. Repeat for 5 random seeds, report mean and std.

    Evaluation tasks (implemented in eval_rewards.py):
      - AntMaze:
        * goal-reaching: reward = -1 until within epsilon of goal, 0 otherwise.
          Goals: specific locations in the maze.
        * directional: reward = dot(desired_direction, velocity_xy) or similar.
        * random-simplex: procedural noise generator (e.g., Perlin noise over xy).
        * path tasks: hand-designed reward functions for edges, loop, center.
      - ExORL:
        * walker/cheetah goals: goal-reaching to random states from dataset.
        * walker/cheetah velocity: forward/backward velocity reward.
      - Kitchen:
        * 7 subtask rewards: binary indicators for each subtask completion
          (e.g., microwave open, light switch on, etc.).

    ============================================================
    COMPONENT 9: Main Entry Point and Configuration (main.py, config.py)
    ============================================================
    - main.py: parse command-line arguments (domain, phase, etc.), run training or evaluation.
    - config.py: central place for all hyperparameters:
      * Encoder: K=32, K'=32, d_embed=128, d_model=256, num_layers=2, num_heads=4,
        d_latent=64, num_reward_bins=64, R_max=10.0, beta_kl=0.1.
      * Decoder: hidden_layers=[256,256], activation='relu'.
      * IQL: hidden_layers=[256,256,256], tau=0.7, beta=3.0, gamma=0.99,
        lr=3e-4, batch_size=256, target_update_rate=0.005.
      * Training: encoder_steps=200000, iql_steps=1000000.
      * Evaluation: K_eval=32, num_episodes=20, num_seeds=5.
