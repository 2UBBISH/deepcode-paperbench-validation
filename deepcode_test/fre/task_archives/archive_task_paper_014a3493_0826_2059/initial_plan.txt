  # SECTION 2: Implementation Components
  implementation_components: |
    === 1. FRE Encoder (encoder.py) ===
    - Purpose: Encode a set of (state, reward) pairs into a latent task vector z.
    - Architecture: Permutation-invariant Transformer (no positional encoding, no causal mask).
    - Input: K states s_k and corresponding scalar rewards η(s_k). Reward is discretized into a learned embedding token space.
      * Reward discretization: Divide reward range (e.g., [-1, 1]) into B bins (e.g., B=64). Each bin has a learnable embedding vector of dimension d_rew (e.g., 64). Scalar reward is mapped to the embedding of its bin.
      * State embedding: Linear projection from state_dim to d_state (e.g., 128).
      * Token construction: Concatenate state embedding and reward embedding → token of dimension d_state + d_rew. Project to d_model (e.g., 256) via linear layer.
    - Transformer: N layers (e.g., 4), M heads (e.g., 4), feedforward dim 4*d_model. No causal mask; self-attention over all tokens.
    - Output: Mean pool the final layer representations across the K tokens → vector h. Two linear heads from h to μ_z and log σ_z (diagonal Gaussian). Latent dimension d_z (e.g., 128).
    - Sampling: z = μ_z + σ_z * ε, ε ~ N(0,I). Use reparameterization.
    - Key formula: p_θ(z | {(s_k, η(s_k))}) = N(μ_z, σ_z^2 I).

    === 2. FRE Decoder (decoder.py) ===
    - Purpose: Predict reward η(s) for a given state s and latent z.
    - Architecture: Feedforward MLP.
    - Input: Concatenate state s and latent z → input vector. Pass through 2-3 hidden layers (e.g., 256 units each, ReLU). Output: scalar reward prediction.
    - Training loss: Mean Squared Error (MSE) between predicted reward and true reward η(s) on K' decoder states (different from encoder states).
    - VAE objective (Equation 6): L_FRE = (1/K') Σ MSE(η(s_d), q_θ(s_d, z)) + β * KL( N(μ_z, σ_z^2 I) || N(0,I) ). β is a hyperparameter (e.g., 1.0).

    === 3. Prior Reward Distribution (prior.py) ===
    - Purpose: Generate diverse unsupervised reward functions for training.
    - Mixture of three types (uniform sampling):
      a) Singleton (Goal-reaching): Sample a goal state g from dataset. Reward η(s) = -1 if ||s - g|| > threshold else 0. (Threshold e.g., 0.5 for AntMaze, task-specific).
      b) Random Linear: Sample a random vector w ~ Uniform(-1,1) of state_dim. Apply sparse mask (e.g., 80% zeros) to bias towards simple functions. Reward η(s) = dot(w, s).
      c) Random MLP: Initialize a 2-layer MLP (hidden dim 64) with random weights (e.g., Kaiming uniform). Reward η(s) = MLP(s). Weights fixed per function.
    - All rewards are normalized to roughly [-1, 1] range via scaling.

    === 4. IQL RL Module (iql.py) ===
    - Purpose: Offline RL algorithm to train policy π(a|s,z), Q-function Q(s,a,z), and value function V(s,z) conditioned on latent z.
    - Networks:
      * V(s,z): MLP with state+s+z input, output scalar.
      * Q(s,a,z): MLP with state+action+z input, output scalar.
      * π(a|s,z): Gaussian policy MLP with state+z input, outputs mean and log_std.
    - IQL losses:
      * L_V = E_{(s,a)~D}[ L2_τ( Q_target(s,a,z) - V(s,z) ) ] where L2_τ(u) = |τ - 1(u<0)| * u^2. τ is expectile (e.g., 0.7). Q_target uses target network.
      * L_Q = E_{(s,a,s')~D}[ ( η(s) + γ * V(s',z) - Q(s,a,z) )^2 ].
      * L_π = E_{(s,a)~D}[ exp( β * (Q(s,a,z) - V(s,z)) ) * log π(a|s,z) ] (AWR). β e.g., 3.0.
    - z is provided by frozen FRE encoder.

    === 5. Training Loop (train_fre.py, train_rl.py) ===
    - Strided training scheme:
      Phase 1 (train_fre.py): Train only encoder+decoder.
        For each iteration:
          - Sample reward function η from prior.
          - Sample K encoder states {s_e} from dataset D, compute rewards.
          - Sample K' decoder states {s_d} from D, compute rewards.
          - Encode to get z, decode to predict rewards on s_d.
          - Compute L_FRE (MSE + KL), update encoder+decoder.
        Converge when loss plateaus.
      Phase 2 (train_rl.py): Freeze encoder. Train IQL networks.
        For each iteration:
          - Sample reward function η from prior.
          - Sample K encoder states, encode to z.
          - Sample RL batch (s,a,s') from D.
          - Compute IQL losses using η(s) as reward, update V, Q, π.
    - Algorithm 1 in paper summarizes this.

    === 6. Evaluation (eval.py) ===
    - Purpose: Zero-shot evaluation on downstream tasks.
    - Given a new reward function η_test (e.g., goal-reaching, directional), sample K=32 states from dataset, compute rewards, encode to z.
    - Rollout policy π(a|s,z) in environment, compute average return over 20 episodes.
    - Tasks implemented:
      * AntMaze: goal-reaching (multiple goals), directional (move in (x,y) direction), random-simplex (procedural noise), path tasks (edges, loop, center).
      * ExORL: goal-reaching (random goals), velocity (forward/backward).
      * Kitchen: 7 subtask reward functions.

    === 7. Data Handling (data.py) ===
    - Load D4RL AntMaze (antmaze-large-diverse-v2), Kitchen (kitchen-complete-v0).
    - Load ExORL datasets (walker, cheetah) from standard sources.
    - Provide normalized state, action, next_state, terminal.

    === 8. Hyperparameters (configs/default.yaml) ===
    - Encoder: K=32, K'=32, d_model=256, n_layers=4, n_heads=4, d_z=128, d_rew_embed=64, B=64.
    - Decoder: hidden dims [256,256].
    - VAE: β=1.0.
    - IQL: τ=0.7, γ=0.99, β=3.0, lr=3e-4, batch_size=256.
    - Prior: uniform mixture, goal threshold=0.5, linear sparsity=0.8, MLP hidden=64.
    - Training: FRE iterations=100k, RL iterations=1M.
