  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    COMPONENT 1: Prior Reward Distribution (reward_prior.py)
    ============================================================
    Purpose: Generate diverse random unsupervised reward functions for FRE training.
    The prior is a uniform mixture of three function families:

    a) Singleton Goal-Reaching Rewards:
       - Sample a goal state s_g uniformly from the offline dataset.
       - Reward: η(s) = -1 if ||s - s_g|| > threshold (goal not reached), 0 otherwise.
       - Implementation: compute distance, threshold can be a small epsilon or task-specific.

    b) Random Linear Functions:
       - Sample a random vector w ~ Uniform(-1, 1) of same dimension as state.
       - Apply sparse mask: randomly zero out elements with probability p_mask (e.g., 0.5) to bias toward simple functions.
       - Reward: η(s) = w^T s (inner product).

    c) Random MLP Functions:
       - Initialize a 2-layer MLP with random weights (e.g., hidden dim 256, ReLU activation).
       - Reward: η(s) = MLP(s).
       - Weights are fixed after initialization (not trained).

    Sampling: For each training iteration, randomly choose one family with equal probability (1/3 each), then sample a function from that family. The function is evaluated on K encoding states and K' decoding states to produce scalar rewards.

    ============================================================
    COMPONENT 2: FRE Encoder (encoder.py)
    ============================================================
    Purpose: Encode a set of (state, reward) pairs into a latent Gaussian distribution p_θ(z | {(s_i, η(s_i))}).

    Architecture:
    - Input: K state-reward pairs. Each state s_i (dim d_s) is concatenated with a learned embedding of its discretized reward.
    - Reward discretization: Scalar reward is bucketed into B bins (e.g., B=100) based on magnitude. Each bin corresponds to a learned embedding vector of dimension d_emb (e.g., 64).
    - The concatenated vector [s_i; emb(η(s_i))] is projected to transformer hidden dimension d_model via a linear layer.
    - Transformer: Stack of L layers (e.g., L=2), each with multi-head self-attention (e.g., H=4 heads) and feedforward sublayers.
      * NO positional encodings.
      * NO causal masking (inputs treated as unordered set).
    - Output: Average pooling over the K output representations -> vector h.
    - Two linear projection heads from h:
        μ = Linear(h)   # mean of latent Gaussian
        log_σ = Linear(h)  # log standard deviation
    - Latent z is sampled via reparameterization: z = μ + ε * exp(log_σ), ε ~ N(0, I).
    - Latent dimension d_z (e.g., 64 or 128).

    Hyperparameters (to be tuned/confirmed):
    - K (number of encoding states): 32
    - d_model: 256
    - L: 2
    - H: 4
    - d_emb: 64
    - B: 100
    - d_z: 64

    ============================================================
    COMPONENT 3: FRE Decoder (decoder.py)
    ============================================================
    Purpose: Predict reward η(s) for a given state s and latent z.

    Architecture:
    - Input: state s (dim d_s) concatenated with latent z (dim d_z).
    - Feedforward MLP: 2-3 hidden layers (e.g., [256, 256]) with ReLU activations.
    - Output: single scalar predicted reward \hat{η}(s).

    ============================================================
    COMPONENT 4: FRE VAE Model (fre_model.py)
    ============================================================
    Purpose: Joint training of encoder and decoder.

    Loss function (Equation 6 in paper, standard β-VAE):
      L = (1/K') Σ_{k=1}^{K'} MSE(η(s_k^d), decoder(s_k^d, z)) + β * KL( N(μ, σ^2) || N(0, I) )
    where:
      - s_k^d are K' decoding states (different from encoding states), K' = 32 typically.
      - z is sampled from encoder given encoding states.
      - β is a hyperparameter (e.g., 0.1 or 1.0).
      - KL divergence: KL = -0.5 * Σ (1 + log_σ - μ^2 - exp(log_σ)).

    Training step:
      1. Sample reward function η from prior.
      2. Sample K encoding states {s_k^e} from dataset uniformly.
      3. Sample K' decoding states {s_k^d} from dataset uniformly (disjoint from encoding states).
      4. Compute rewards for both sets using η.
      5. Forward encoder: get μ, log_σ from encoding pairs.
      6. Sample z ~ N(μ, σ^2).
      7. Forward decoder: predict rewards for decoding states given z.
      8. Compute loss, backpropagate through both encoder and decoder.

    ============================================================
    COMPONENT 5: Implicit Q-Learning Agent (iql.py)
    ============================================================
    Purpose: Offline RL algorithm that learns z-conditioned Q, V, and policy.

    Networks (all conditioned on z by concatenating z to state input):
    - Q-network: MLP(s, a, z) -> scalar Q-value. Two Q-networks for double Q-learning.
    - V-network: MLP(s, z) -> scalar value.
    - Policy π(a|s, z): Gaussian policy, MLP(s, z) -> mean, log_std.

    IQL Losses (from Kostrikov et al., 2021):
    - V loss: L_V = E_{(s,a)~D}[ L2_τ( Q_target(s,a,z) - V(s,z) ) ]
      where L2_τ(u) = |τ - 1(u<0)| * u^2, τ is expectile (e.g., 0.7).
    - Q loss: L_Q = E_{(s,a,r,s')~D}[ (r + γ * V_target(s',z) - Q(s,a,z))^2 ]
    - Policy loss: L_π = E[( exp( (Q(s,a,z) - V(s,z)) / temperature ) * log π(a|s,z) )]
      (advantage-weighted regression with temperature α, e.g., α=3.0).

    Target networks: Polyak averaging for V and Q targets.

    z-conditioning: During RL training, z is produced by the frozen FRE encoder from K encoding states and their rewards under the sampled η. z is then concatenated to state (and action for Q) inputs.

    ============================================================
    COMPONENT 6: Two-Phase Trainer (trainer.py)
    ============================================================
    Purpose: Orchestrate the training procedure as described in Algorithm 1.

    Phase 1: FRE Encoder Pretraining
      - While not converged:
          Sample η ~ p(η)
          Sample K encoder states, K' decoder states from dataset
          Compute FRE loss (MSE + KL)
          Update encoder and decoder parameters
      - Convergence criterion: loss plateaus or fixed number of steps (e.g., 100k gradient steps).

    Phase 2: Offline RL Training with Frozen Encoder
      - Freeze encoder parameters.
      - While not converged:
          Sample η ~ p(η)
          Sample K encoder states, compute rewards, encode to z
          Sample RL batch (s, a, r=η(s), s') from dataset
          Update Q, V, policy using IQL losses with z conditioning
      - Note: The same η is used to compute rewards for the RL batch and to produce z.

    Strided training: Phase 1 runs exclusively first, then Phase 2 runs exclusively. No interleaving.

    ============================================================
    COMPONENT 7: Data Utilities (data_utils.py)
    ============================================================
    - Load D4RL datasets (AntMaze, Kitchen) using d4rl library.
    - Load ExORL datasets (Walker, Cheetah) from ExORL benchmark (Yarats et al., 2022) – may require custom loading or use of provided datasets.
    - Replay buffer: store all (s, a, r, s', done) tuples from offline dataset.
    - Sampling functions: uniform sampling of states for encoder/decoder, batch sampling for RL.
