  # SECTION 2: Implementation Components
  implementation_components: |
    === 1. Mask Network (mask_net.py) ===
    - Purpose: Learn a binary policy π̃(a^e|s) that decides whether to randomize the action (a^e=1) or keep the target agent's action (a^e=0). The probability of keeping the action ξ(s)=π̃(a^e=0|s) serves as the importance score; higher ξ means more critical.
    - Architecture: MLP with input dim = state_dim, hidden layers [128, 128] (or matching target policy), output dim = 2 (for two discrete actions). Includes a value head (separate linear layer) for baseline in PPO.
    - Training algorithm: Proximal Policy Optimization (PPO) adapted for discrete actions.
    - Perturbed policy behavior: At state s, sample a^e ~ π̃(·|s). If a^e=0, sample action a ~ π_target(·|s); if a^e=1, sample a ~ Uniform(A). Execute a, observe environment reward r_env.
    - Intrinsic reward: r_int = α * I(a^e == 1). Total reward: r_total = r_env + r_int. α balances masking encouragement vs. performance; default α=0.0001 (or 0.01 per text).
    - Objective: Maximize J(π̃) = E[ Σ γ^t (r_env_t + α * I(a^e_t=1)) ].
    - Training loop:
      1. Collect N trajectories using perturbed policy.
      2. Compute discounted returns and advantages (GAE) using the value head.
      3. Update π̃ via PPO clipped objective: L^CLIP(θ) = E[ min( ratio * A, clip(ratio, 1-ε, 1+ε) * A ) ].
      4. Update value head via MSE loss on returns.
      5. Repeat until convergence (fidelity stabilizes).
    - Key formulas:
      - ξ(s) = softmax(π̃(s))[0]
      - Importance score = ξ(s)
      - Perturbed policy: π̄(a|s) = ξ(s) π_target(a|s) + (1-ξ(s)) π_random(a|s)

    === 2. Random Network Distillation (rnd.py) ===
    - Purpose: Provide an exploration bonus to encourage visiting novel states during refining.
    - Components:
      - Target network f: fixed, randomly initialized MLP (input=state_dim, hidden=[64,64], output=embedding_dim e.g. 64).
      - Predictor network f̂: same architecture, trained to predict f(s).
    - Bonus: r_rnd(s) = ||f̂(s) - f(s)||² (MSE).
    - Training: During refining, after each trajectory, update f̂ by minimizing MSE loss on collected states (using Adam optimizer, lr=1e-4).
    - Combined reward for refining: r_total = r_env + λ * r_rnd(s). λ balances exploration; typical values {0.1, 0.01, 0.001} (default 0.01).

    === 3. Refining Algorithm (refine.py) ===
    - Purpose: Improve a pre-trained target agent π_target by resetting to critical states and exploring with RND.
    - Steps:
      1. **Critical State Collection**:
         - Run π_target for M episodes, saving full environment state at each step.
         - For each state s, compute importance score = ξ(s) using trained mask network.
         - Select the state with maximum importance per episode (or top-k overall) as critical states. Store their environment states.
      2. **Mixed Initial Distribution**:
         - With probability p, sample uniformly from the set of saved critical states and restore environment to that state (using env_wrappers).
         - With probability 1-p, use the environment's default reset.
         - p is a hyperparameter; typical values {0.25, 0.5} (default 0.25 or 0.5 per application).
      3. **Refining Loop** (using PPO):
         - Initialize RND predictor.
         - For each iteration:
           a. Reset env using mixed distribution.
           b. Run current policy π (initially π_target) to collect a trajectory; at each step compute r_rnd and add to reward.
           c. Store trajectory (s, a, r_total, ...).
           d. Update RND predictor on collected states.
           e. After collecting a batch of trajectories, update π via PPO (using combined rewards).
         - Repeat until performance plateaus.
    - Theoretical guarantees (reproduced in code comments):
      - Theorem 3.3: η(π̄) ≤ η(π) under Assumption 3.1 (masking only non-critical steps does not increase performance).
      - Lemma 3.5: MaskNet-based sampling is equivalent to sampling from a better policy π̂ (V^π̂ ≥ V^π).
      - Theorem 3.6: After refining, V^π*(ρ) - V^π'(ρ) ≤ O( ε/(1-γ)² ||d_ρ^π* / d_ρ^π̂||_∞ ), showing the bound tightens with better explanation.

    === 4. Environment Wrappers (env_wrappers.py) ===
    - Provides a unified interface for saving/restoring environment states.
    - For MuJoCo: use sim.get_state() / sim.set_state() (serializable).
    - For other envs: custom implementations (e.g., for MetaDrive, save vehicle state dict; for Malconv, save malware file state; for CAGE2, save network state snapshot).
    - Wrapper class: `StateSaveWrapper` with methods `save_state()`, `restore_state(state)`, and `reset_to_state(state)`.

    === 5. Baselines ===
    - StateMask: Use original implementation (https://github.com/nuwuxian/RL-state_mask) but adapt to same environments for fair comparison. Measures fidelity and training time.
    - Jump-Start RL (JSRL): Implement as per Uchendu et al. (2023): use pre-trained policy to guide initial exploration, then fine-tune.
    - Self-Imitation Learning (SIL): Prioritize transitions with positive advantages in replay buffer (Oh et al., 2018).
    - Random Explanation: Replace mask network importance scores with random scores; otherwise same refining pipeline.

    === 6. Hyperparameters (from Table 3 and Appendix C.3) ===
