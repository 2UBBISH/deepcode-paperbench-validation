  # SECTION 2: Implementation Components
  implementation_components: |
    ============================================================
    1. MASK NETWORK (Explanation Method)
    ============================================================
    Purpose: Identify critical states where the agent's action strongly influences the final return.
    Architecture: Multi-layer perceptron (MLP) with same hidden sizes as the target policy network
                 (e.g., 4 layers × 128 units for selfish mining; for MuJoCo, 2 layers × 64 units).
                 Input: state vector s. Output: ξ(s) = probability of keeping the original action (a^e=0).
                 The mask network defines a perturbed policy:
                   π̄(a|s) = ξ(s) * π(a|s) + (1-ξ(s)) * π^r(a|s)
                 where π is the target policy and π^r is a uniform random policy.

    Training Objective: Maximize the expected return of the perturbed policy plus an intrinsic reward
                        that encourages blinding (i.e., outputting a^e=1).
    Intrinsic reward at step t: r_int(t) = α * (1 - ξ(s_t))   [α from Table 3, typically 0.0001]
    Total reward for mask network: r_total = r_env + r_int
    Training algorithm: PPO (Proximal Policy Optimization) on the mask network parameters θ_m.
    The mask network is trained on-policy: collect trajectories by running the perturbed policy
    in the environment, compute advantages using GAE, update θ_m via PPO clipped objective.

    Pseudocode:
      for iteration in 1..M:
          collect trajectories using π̄ (mix of π and random)
          for each step t:
              r_total_t = r_env_t + α * (1 - ξ(s_t))
          compute advantages A_t using GAE on r_total
          update mask network θ_m with PPO loss:
              L = -E[min(ratio * A, clip(ratio, 1-ε, 1+ε) * A)]
          (optional) add entropy bonus

    ============================================================
    2. EXPLANATION EXTRACTION
    ============================================================
    Purpose: Given a trained mask network, compute importance scores for states in a trajectory.
    Importance score: I(s) = ξ(s)  (higher ξ means action is more critical; the mask network
                       chooses to keep the original action).
    Critical state selection: For each trajectory, rank states by I(s) descending.
                              Select the top-k states (e.g., k=1 or top 10%) as critical states.
                              Store these states (full environment state vector) in a buffer.
    Implementation: 
      - Run the target policy π to collect N trajectories.
      - For each trajectory, record all (s, a, r, s') and compute ξ(s) via mask network.
      - Extract the state with maximum ξ(s) per trajectory (or top-p fraction).
      - Save the environment state (using simulator's state dictionary) for later restoration.

    ============================================================
    3. MIXED INITIAL STATE DISTRIBUTION
    ============================================================
    Purpose: During refining, start episodes from a blend of default initial states and critical states.
    Sampling procedure:
      With probability p (hyperparameter, e.g., 0.25 or 0.5):
          Sample a critical state uniformly from the critical state buffer.
          Reset the environment to that exact state (using state restoration).
      With probability (1-p):
          Reset the environment to the default initial state (env.reset()).
    This encourages the agent to learn from both the original task and the critical situations.

    ============================================================
    4. RANDOM NETWORK DISTILLATION (RND) EXPLORATION BONUS
    ============================================================
    Purpose: Encourage the agent to visit novel states during refining, preventing local optima.
    Components:
      - Target network: f_target(s) -> R^k, randomly initialized and fixed.
      - Predictor network: f_pred(s) -> R^k, trained to predict f_target(s).
    Exploration bonus: r_rnd(s) = ||f_pred(s) - f_target(s)||^2  (MSE).
    Training: During refining, update f_pred using SGD on the collected states to minimize MSE.
    Total reward during refining: r_total = r_env + λ * r_rnd(s)
    λ is a hyperparameter (e.g., 0.01 or 0.001) balancing environment reward and exploration.

    ============================================================
    5. REFINING ALGORITHM (RICE)
    ============================================================
    Purpose: Improve the target policy π using the mixed initial distribution and RND bonus.
    Algorithm:
      Input: pre-trained policy π, mask network θ_m, critical state buffer B,
             hyperparameters p, λ, α, PPO parameters.
      Initialize RND predictor network f_pred.
      For each refining iteration:
          Sample initial state: with prob p from B, else default.
          Reset environment to chosen initial state.
          Run episode using current policy π (being refined).
          At each step, compute r_total = r_env + λ * ||f_pred(s) - f_target(s)||^2.
          Store transitions.
          Update f_pred on collected states (minimize MSE).
          After collecting a batch of trajectories, update π using PPO on r_total.
      Continue until convergence or fixed number of steps.

    ============================================================
    6. ENVIRONMENT STATE SAVE/RESTORE
    ============================================================
    For MuJoCo: Use env.sim.get_state() and env.sim.set_state() to save/restore full physics state.
    For other environments: Implement similar get_state/set_state methods.
    The state buffer stores the serialized state dictionaries.

    ============================================================
    7. BASELINE METHODS
    ============================================================
    - PPO fine-tuning: Continue training π with default initial states, no RND.
    - StateMask-R: Use StateMask for explanation, then refine with mixed init (no RND).
    - Jump-Start RL (JSRL): Use a curriculum of starting states from expert demonstrations.
    - Self-Imitation Learning (SIL): Prioritize past successful experiences in replay buffer.
    - Random explanation: Replace mask network with random importance scores.
    - Integrated Gradients / AIRS: Alternative explanation methods for ablation.
