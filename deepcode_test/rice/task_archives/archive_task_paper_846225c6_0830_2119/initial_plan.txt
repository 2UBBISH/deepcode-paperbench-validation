  # SECTION 2: Implementation Components
  implementation_components: |
    ## 1. Target Agent Training (`train_agent.py`)
    - **Purpose**: Train a base PPO agent on the given environment until convergence.
    - **Implementation**: Uses Stable-Baselines3 (SB3) PPO with default architecture (MLP policy, 2 layers of 64 units for MuJoCo; for other envs, follow paper specs: e.g., selfish mining uses 4-layer MLP with hidden size 128).
    - **Output**: Saved model weights and training curves.

    ## 2. Mask Network (`mask_network.py`)
    - **Purpose**: Learn a binary policy ξ(s) that decides whether to take the agent's action (aᵉ=0) or a random action (aᵉ=1). Trained to maximize perturbed policy performance while encouraging blinding via intrinsic reward.
    - **Architecture**: MLP with same hidden structure as the agent policy. Input: state vector s. Output: 2 logits for binary action.
    - **Training Algorithm** (simplified from StateMask):
      1. Wrap the environment with `PerturbedEnv` (see below).
      2. The mask network acts as a PPO agent with Discrete(2) action space.
      3. At each step t, sample aᵉₜ ~ ξ(·|sₜ). If aᵉₜ=0, execute agent action aₜ ~ π(·|sₜ); if aᵉₜ=1, execute random action aₜ ~ Uniform(A).
      4. The reward for the mask network is: r_maskₜ = r_envₜ + α * I(aᵉₜ = 1), where α is a small coefficient (default 0.0001) and I is the indicator.
      5. Update ξ using PPO clipped loss on the cumulative discounted r_mask.
    - **Hyperparameters**: α = 0.0001 (Table 3). Number of training samples: 3×10⁵ for MuJoCo, 1.5×10⁶ for selfish mining, 1×10⁷ for CAGE, 2.44×10⁶ for auto driving, 32349 for malware (Table 4).
    - **Key Formula**: The perturbed policy is π̄(a|s) = ξ(aᵉ=0|s) π(a|s) + (1-ξ(aᵉ=0|s)) πʳ(a|s).

    ## 3. Perturbed Environment Wrapper (`perturbed_env.py`)
    - **Purpose**: Create a wrapper that interposes the mask network between the agent and the environment.
    - **Implementation**: A Gym wrapper that holds references to the frozen agent policy π and the mask network ξ. On `step()`, it computes mask action, selects the actual action, and returns the next state, r_mask, done, info. The observation space is the original state space; action space is Discrete(2) for the mask.

    ## 4. Explanation Extraction (`explanation.py`)
    - **Purpose**: After training ξ, compute importance scores for states and identify critical states.
    - **Algorithm**:
      1. For each trajectory τ collected by running π (or π̄), for each state sₜ:
         - Compute importance I(sₜ) = 1 - ξ(aᵉ=0 | sₜ) = probability of NOT randomizing.
         - Higher I means more critical.
      2. Select the state with maximum I in τ as the critical state s*.
      3. Store s* in a buffer D (with optional metadata: action, next state, etc.).
    - **Theoretical basis**: I(s) ∝ Q_diff = Q^π(s,a) - E_a'[Q^π(s,a')]; larger Q_diff indicates higher criticality.

    ## 5. Random Network Distillation (`rnd.py`)
    - **Purpose**: Provide an exploration bonus during refining to encourage visiting novel states.
    - **Architecture**:
      - Target network f_target: fixed, randomly initialized MLP mapping state → embedding (dim 128).
      - Predictor network f_pred: same architecture, trained to minimize MSE(f_pred(s), f_target(s)).
    - **Bonus**: r_rnd(s) = ||f_pred(s) - f_target(s)||².
    - **Training**: During refining, update f_pred using Adam optimizer on collected states to minimize MSE. The target network is never updated.

    ## 6. Refining Process (`refining.py`)
    - **Purpose**: Improve the pre-trained agent π by continuing training with a mixed initial state distribution and RND exploration bonus.
    - **Algorithm**:
      1. Load pre-trained agent π and critical state buffer D.
      2. Initialize RND predictor f_pred and target f_target.
      3. For each episode:
         - Sample initial state: with probability p, draw s₀ ~ Uniform(D); with probability 1-p, use environment's default reset.
         - Reset environment to s₀ (using `set_state` if available; otherwise use goal-conditioned approach or store/restore).
         - Run agent π in environment, collecting trajectory.
         - For each step t, compute augmented reward: r'_t = r_envₜ + λ * r_rnd(sₜ).
         - Store transitions (sₜ, aₜ, r'_t, sₜ₊₁, done) in PPO buffer.
      4. After collecting a batch, update π using PPO on augmented rewards.
      5. Update f_pred on the collected states (MSE loss).
      6. Repeat for a fixed number of timesteps (e.g., 1×10⁶ for MuJoCo).
    - **Hyperparameters**: p ∈ {0.25, 0.5} (Table 3), λ ∈ {0.001, 0.01} (Table 3), α = 0.0001. RND embedding dim = 128, predictor learning rate = 1e-4.
    - **Theoretical Guarantee**: Under Assumptions 3.1-3.4, the refined policy π' satisfies V^π*(ρ) - V^π'(ρ) ≤ O(ε/(1-γ)² ||d^π*_ρ / d^π̂_ρ||∞), and using our explanation tightens the bound (Theorem 3.6, Lemma 3.5).

    ## 7. Baselines (`baselines/`)
    - **StateMask** (`statemask.py`): Original mask network training using Lagrangian method. Reuse released code or reimplement.
    - **Jump-Start RL** (`jsrl.py`): Use existing implementation from https://github.com/steventango/jumpstart-rl.
    - **Self-Imitation Learning** (`sil.py`): Prioritize past successful experiences in replay buffer.
    - **Random Explanation** (`random_explanation.py`): Randomly select states as critical; otherwise same refining pipeline.
    - **PPO Fine-tuning**: Continue training PPO without resetting or exploration bonus.

    ## 8. Custom Environments (`envs/`)

    - **CAGE Challenge 2** (`cage_env.py`): Use champion scheme from Cardiff (git, c). Blue agent PPO defending against red agent "B-line". Actions: Monitor, Analyze, Decoy*, Remove, Restore. Reward: negative when red gains admin access.
    - **Autonomous Driving** (`auto_driving_env.py`): MetaDrive "Macro-v1" environment. State: vector of BEV + sensor info. Actions: steering, acceleration, brake (normalized to [-1,1]²). Reward: forward motion, speed maintenance, collision penalties.
    - **Malware Mutation** (`malware_env.py`): MalConv gym environment from (git, a). State: feature vector of malware. Actions: 16 mutation operations (Table 2). Reward: 10 for evasion, otherwise sc₀ - scₜ.
