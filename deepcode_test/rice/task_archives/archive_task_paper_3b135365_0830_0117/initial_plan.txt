  implementation_components: |
    ==============================
    1. MASK NETWORK (Explanation Method)
    ==============================
    Purpose: Learn a policy that decides, at each state, whether to mask (randomize) the target agent's action.
    The trained mask network provides importance scores for states: critical states are those where masking would hurt performance.

    Architecture:
      - Input: state vector s (same as target agent's observation).
      - Output: logits for two actions: a^e = 0 (not mask) and a^e = 1 (mask).
      - Network: MLP with 2 hidden layers of 256 units, ReLU activation (same as target policy for fair comparison).
      - Softmax to get probabilities: ξ(s) = P(a^e=0|s), 1-ξ(s) = P(a^e=1|s).

    Training Algorithm (simplified from StateMask, with intrinsic reward):
      Hyperparameters: α (intrinsic reward coefficient, default 0.0001), learning rate 3e-4, PPO epochs 10, batch size 64.
      For each training iteration:
        1. Collect N trajectories using the perturbed policy π_bar:
           - At state s_t, sample a^e_t ~ MaskNet(s_t).
           - If a^e_t == 0: take action a_t ~ π_target(s_t)  (original policy)
           - If a^e_t == 1: take action a_t ~ Uniform(A)      (random action)
           - Execute a_t, receive environment reward r_env_t, next state s_{t+1}.
           - Compute mask reward: r_mask_t = r_env_t + α * a^e_t   (bonus for masking)
           - Store (s_t, a^e_t, r_mask_t, s_{t+1}, done) in buffer.
        2. Update MaskNet using PPO on the collected buffer to maximize expected cumulative r_mask.
        3. Clear buffer.
      The intrinsic reward α * a^e_t encourages the mask network to blind (mask) more states, but only when doing so does not significantly reduce the environment reward. Thus, after training, the mask network learns to avoid masking critical states (low 1-ξ(s)) and freely mask non-critical ones (high 1-ξ(s)).

    Importance Extraction:
      For a given state s, importance score I(s) = ξ(s) = P(a^e=0|s) (probability of NOT masking).
      Higher I(s) → more critical state. These scores are used to select the top-K critical states for refinement.

    Fidelity Score:
      Fidelity = (performance of π_bar when masking only the bottom-K non-critical states) / (performance of original π).
      Implemented by: given a trajectory, sort states by I(s) ascending, mask the first K states (lowest importance), measure return.

    ==============================
    2. RICE REFINING ALGORITHM
    ==============================
    Purpose: Improve a pre-trained target agent π by focusing training on critical states and encouraging exploration.

    Steps:
      a. Critical State Identification:
         - Run π for M episodes, collect all visited states.
         - For each state, compute importance I(s) using trained MaskNet.
         - Select the top-K states with highest I(s) as the critical state set C.
           (K is a hyperparameter; paper uses top 10% or a fixed number per episode.)
         - Store the full environment state (not just observation) for each critical state to allow exact restoration.

      b. Mixed Initial Distribution:
         - At the start of each refining episode:
           With probability p: sample a state s0 uniformly from C, reset environment to s0 (using state restoration).
           With probability 1-p: reset environment to its default initial state distribution.
         - p is a hyperparameter (paper tests {0, 0.25, 0.5, 0.75, 1}; best usually 0.25 or 0.5).

      c. Exploration Bonus via Random Network Distillation (RND):
         - Two networks: a fixed randomly initialized target network f: S → R^d, and a trainable predictor network f_hat: S → R^d.
         - At each step, intrinsic reward r_rnd = ||f_hat(s') - f(s')||^2 (prediction error).
         - Total reward for refining: r_total = r_env + λ * r_rnd.
         - λ balances exploration (paper tests {0.1, 0.01, 0.001}; best usually 0.01).
         - Predictor f_hat is updated online (SGD) to minimize MSE on visited states.

      d. Policy Refinement:
         - Continue training the target agent π (now called π') using the same base RL algorithm (PPO).
         - Use the mixed initial distribution and augmented reward r_total.
         - Train for a fixed number of additional timesteps (paper uses 1e6 for MuJoCo, varies per application).
         - Output refined policy π'.

    State Restoration:
      For MuJoCo: use env.set_state(qpos, qvel) after storing them.
      For other environments: implement a wrapper that saves/loads the full internal state (if supported) or replays actions from the beginning to reach the critical state (less efficient but general). The paper notes compatibility with goal-conditioned policies as an alternative.

    ==============================
    3. BASELINE METHODS
    ==============================
    - PPO Fine-tuning: Continue training π from default initial states, no explanation, no exploration bonus.
    - StateMask-R: Use the original StateMask implementation (from github.com/nuwuxian/RL-state_mask) to identify critical states, then apply the same mixed-initial + exploration refinement.
    - Jump-Start RL (JSRL): Use the implementation from github.com/steventango/jumpstart-rl. Pre-train a guide policy, then use it to initialize exploration.
    - Self-Imitation Learning (SIL): Modify the replay buffer to prioritize episodes with high return; update policy using both PPO loss and SIL loss (Oh et al., 2018).
    - Random Explanation: Replace MaskNet importance scores with random values; otherwise same refinement.
    - Integrated Gradients / AIRS: Use these explanation methods to score states, then apply the same refinement pipeline.

    ==============================
    4. ENVIRONMENTS & REWARD MODIFICATIONS
    ==============================
    MuJoCo (dense): Hopper-v3, Walker2d-v3, Reacher-v2, HalfCheetah-v3. Use Stable-Baselines3 built-in wrappers.
    MuJoCo (sparse): Modify reward to be 0 unless x-coordinate > threshold (0.6 for Hopper/Walker2d, 5 for HalfCheetah). Reacher remains dense (no sparse variant in paper).
    Selfish Mining: Custom environment from https://github.com/roibarzur/pto-selfish-mining. State: blockchain state vector. Actions: Adopt, Reveal, Mine. Reward: +1 for accepted block, penalty for failed action.
    CAGE Challenge 2: Use the champion blue agent scheme from https://github.com/john-cardiff/-cyborg-cage-2. Action space: Monitor, Analyze, Decoy*, Remove, Restore. Reward: negative while red has admin access.
    Autonomous Driving: MetaDrive "Macro-v1" environment. State: vector of road/sensor info. Actions: steering, acceleration, brake. Reward: forward progress, collision penalties.
    Malware Mutation: MalConv gym environment from https://github.com/bfilar/malware_rl. State: feature vector of PE file. Actions: 16 mutation operations (Table 2). Reward: 10 for evasion, otherwise score difference.

    ==============================
    6. THEORETICAL GUARANTEES (not implemented, but referenced)
    ==============================
    - Theorem 3.3: Perturbed policy η(π_bar) ≤ η(π) under Assumption 3.1 (masking only reduces or maintains performance).
    - Lemma 3.5: MaskNet-based sampling is equivalent to sampling from a better policy π_hat (V^π_hat ≥ V^π).
    - Theorem 3.6: Performance bound after refinement: V^π*(ρ) - V^π'(ρ) ≤ O(ε/(1-γ)^2 * ||d_ρ^π* / d_ρ^π_hat||_∞). Using our explanation tightens the bound (smaller distribution mismatch coefficient).
    These proofs are not required for implementation but validate the approach.
