    ============================================
    COMPONENT 1: Mask Network (Explanation Method)
    ============================================
    Purpose: Train a policy network that outputs a binary mask action (0=use agent action, 1=use random action) to identify critical states. The mask network is trained via RL with an augmented reward.

    File: rice/mask_net.py, agents/mask_agent.py

    Architecture:
      - Input: state vector s (same as target agent's observation)
      - Network: MLP with 2 hidden layers of 256 units each, ReLU activation
      - Output: 2 logits for mask actions {0, 1}, softmax to get probabilities ξ(s) = P(a_e=0|s) and 1-ξ(s) = P(a_e=1|s)

    Training Algorithm (Mask Agent):
      - Use PPO (Schulman et al., 2017) to train the mask network.
      - Rollout procedure:
          1. Reset environment to initial state.
          2. For each step t:
             a. Get target agent's action a_target = π_target(s_t)
             b. Sample mask action a_e ~ MaskNet(s_t)
             c. If a_e == 0: execute a_target
                If a_e == 1: execute random action a_r ~ Uniform(A)
             d. Receive environment reward r_env from environment
             e. Compute intrinsic reward: r_intrinsic = 1 if a_e == 1 else 0
             f. Total reward for mask agent: r_mask = r_env + α * r_intrinsic
             g. Store (s_t, a_e, r_mask) in buffer
          3. After collecting a batch of trajectories, update MaskNet using PPO loss:
             L = -E[ min(ratio * A, clip(ratio, 1-ε, 1+ε) * A) ] + c * H(π_mask)
             where ratio = π_mask(a_e|s) / π_old(a_e|s), A is GAE advantage.
      - Hyperparameters for mask training:
          * Learning rate: 3e-4
          * PPO clip ε: 0.2
          * GAE λ: 0.95
          * Discount γ: 0.99
          * Entropy coefficient c: 0.01
          * Batch size: 64
          * Epochs per update: 10
          * α (intrinsic reward coefficient): 0.0001 (default, tuned per application)
      - The target agent π_target is FROZEN during mask training.

    Critical State Identification (file: rice/explanation.py):
      - After training, for each trajectory collected with the target agent:
          1. Compute importance score for each state: I(s) = ξ(s) = P(a_e=0|s) (higher means more critical)
          2. Identify the state with maximum I(s) as the "most critical state" for that trajectory.
          3. Alternatively, collect all states where I(s) > threshold (e.g., 0.5).
      - Store critical states in a buffer for refining.

    Theoretical Basis (from paper):
      - The mask network approximates Q_diff = Q^π(s,a) - E_a'[Q^π(s,a')].
      - Lemma 3.5: MaskNet-based sampling is equivalent to sampling from a better policy π_hat.
      - Theorem 3.3: The perturbed policy's performance is upper bounded by original policy given Assumption 3.1 (random actions are suboptimal).

    ============================================
    COMPONENT 2: Refining Method (RICE)
    ============================================
    Purpose: Improve the target agent by restarting training from a mixed initial distribution (critical states + default) with exploration bonuses.

    File: rice/refining.py, rice/rnd.py

    Mixed Initial Distribution:
      - Given set of critical states S_crit collected from explanation phase.
      - At each episode reset:
          With probability p: sample uniformly from S_crit and set environment state to that critical state.
          With probability 1-p: use default environment initial state distribution.
      - Implementation: Use environment wrapper that overrides reset() to either restore a saved state or call original reset(). For MuJoCo, use set_state() to restore full simulator state (qpos, qvel). For other envs, implement state saving/loading as needed.

    Exploration Bonus (RND):
      - Implement Random Network Distillation (Burda et al., 2018):
          * Target network: fixed randomly initialized MLP (input: state, output: embedding of size 128)
          * Predictor network: trainable MLP (same architecture) trained to predict target network's output.
          * Exploration bonus: r_rnd = || f_predictor(s) - f_target(s) ||^2
      - Total reward during refining: r_total = r_env + λ * r_rnd
      - λ is a hyperparameter balancing exploration (default 0.01, tuned per application).
      - RND predictor is updated alongside the agent's policy using MSE loss.

    Refining Procedure:
      - Initialize refined agent π_ref with same architecture as π_target (or load π_target weights).
      - Use PPO to train π_ref with the mixed initial distribution and RND-augmented reward.
      - Hyperparameters for refining:
          * p (mixture probability): 0.25 or 0.5 (tuned per application, see Table 3)
          * λ (RND coefficient): 0.001, 0.01, or 0.1 (tuned)
          * PPO hyperparameters: same as original agent training (or slightly reduced learning rate)
          * Training steps: until convergence (e.g., 1e6 additional steps for MuJoCo)
      - The refined agent is evaluated from default initial states (not critical states) to ensure generalization.

    Theoretical Guarantee (Theorem 3.6):
      - Under Assumption 3.4 (distribution mismatch coefficient), the refined policy's suboptimality is bounded:
        V^π*(ρ) - V^π'(ρ) ≤ O( ε / (1-γ)^2 * || d_ρ^π* / d_ρ^π_hat ||_∞ )
      - Using MaskNet-based sampling reduces the distribution mismatch coefficient compared to random explanation, tightening the bound.
