  implementation_components: |
    ============================================================================
    1. MASK NETWORK (MaskNet) – core/mask_network.py
    ============================================================================
    Purpose: Learn a binary policy π̃(aᵉ|s) that decides whether to use the target
    agent's action (aᵉ=0) or a random action (aᵉ=1). The mask network is trained
    to maximize the perturbed policy's return while being encouraged to mask more
    via an intrinsic reward.

    Architecture:
      - Input: state vector s (same as target agent's observation)
      - Output: probability of masking ξ(s) = π̃(aᵉ=1|s)
      - Network: MLP with same hidden sizes as the target agent's policy network
        (e.g., 2 hidden layers of 64 units for MuJoCo; 4 layers of 128 for selfish mining)
      - Action sampling: aᵉ ~ Bernoulli(ξ(s))

    Training algorithm (simplified StateMask with intrinsic reward):
      For each episode:
        1. Reset environment to initial state s₀
        2. For t = 0..T:
           a. Sample mask decision aᵉₜ ~ MaskNet(sₜ)
           b. If aᵉₜ == 0: aₜ = π_target(sₜ)   (target agent's action)
              If aᵉₜ == 1: aₜ ~ Uniform(A)      (random action)
           c. Execute aₜ in environment → sₜ₊₁, r_envₜ
           d. Compute intrinsic reward: r_intₜ = aᵉₜ  (1 if masked, 0 otherwise)
           e. Total reward for MaskNet: rₜ = r_envₜ + α * r_intₜ
           f. Store (sₜ, aᵉₜ, rₜ, sₜ₊₁) in MaskNet buffer
        3. Update MaskNet using PPO (or the same RL algorithm as target agent)
           with the collected trajectories.

    Hyperparameters:
      - α (alpha): coefficient for intrinsic reward (default 0.0001, from Table 3)
      - PPO hyperparameters: same as target agent training (learning rate, clip range, etc.)
      - Number of training samples: environment-specific (see Table 4)

    Key formula (from paper):
      The perturbed policy is: π̄(·|s) = ξ(s)·π(·|s) + (1-ξ(s))·πʳ(·|s)
      where π is target agent, πʳ is uniform random policy.
      Theorem 3.3 proves η(π̄) ≤ η(π) under Assumption 3.1 (Aπ(s,a) ≤ 0 for random actions).

    ============================================================================
    2. EXPLANATION EXTRACTION – core/explanation.py
    ============================================================================
    Purpose: After training MaskNet, compute importance scores for states and
    identify critical states for refining.

    Importance score for state s:
      I(s) = 1 - ξ(s) = π̃(aᵉ=0|s)
      (probability that MaskNet chooses NOT to mask, i.e., trusts the target agent)

    Critical state selection:
      - Collect a large set of states from the target agent's replay buffer or by
        rolling out the target agent.
      - Compute I(s) for each state using the trained MaskNet.
      - Select top-K states (e.g., top 10%) or states with I(s) > threshold.
      - Store these critical states in a buffer for refining (core/buffer.py).

    Fidelity metric (Experiment I):
      For a trajectory, the fidelity of an explanation method is measured by how
      well the identified critical steps predict the actual reward change when
      those steps are perturbed. Implementation: compare the reward drop when
      randomizing actions at the top-ranked critical steps vs. random steps.

    ============================================================================
    3. RANDOM NETWORK DISTILLATION (RND) – core/rnd.py
    ============================================================================
    Purpose: Provide an exploration bonus during refining to encourage the agent
    to visit novel states.

    Components:
      - Target network: f_target(s) → ℝᵏ, randomly initialized and fixed.
      - Predictor network: f_pred(s) → ℝᵏ, trained to minimize MSE to f_target(s).
      - Exploration bonus: r_rnd(s) = ||f_pred(s) - f_target(s)||²

    Architecture:
      - Both networks: MLP with same hidden sizes as target agent's policy network.
      - Output dimension k: 64 (typical for RND).

    Training:
      - During refining, after each step, update predictor on the collected states
        using SGD/Adam to minimize MSE.
      - The bonus r_rnd is added to the environment reward for the target agent.

    ============================================================================
    4. REFINING PROCESS – core/refining.py
    ============================================================================
    Purpose: Fine-tune the target agent using a mixed initial state distribution
    and RND exploration bonus.

    Algorithm (RICE refining):
      Input: target agent π, MaskNet π̃, critical state buffer B, hyperparameters p, λ
      Initialize RND predictor and target networks.
      For each refining episode:
        1. Sample u ~ Uniform(0,1)
           If u < p:
             Sample a critical state s_crit from B (uniformly or weighted by importance)
             Reset environment to s_crit (using env.reset_to_state(s_crit))
           Else:
             Reset environment to default initial state.
        2. For t = 0..T:
           a. Select action aₜ ~ π(sₜ)  (target agent's action)
           b. Execute aₜ → sₜ₊₁, r_envₜ
           c. Compute RND bonus: r_rndₜ = ||f_pred(sₜ₊₁) - f_target(sₜ₊₁)||²
           d. Total reward for agent: rₜ = r_envₜ + λ * r_rndₜ
           e. Store transition in agent's PPO buffer.
           f. Update RND predictor on (sₜ₊₁, f_target(sₜ₊₁)).
        3. Update target agent π using PPO with the collected trajectories.

    Hyperparameters:
      - p: mixture probability for critical state initialisation (Table 3: 0.25 or 0.5)
      - λ: exploration bonus coefficient (Table 3: 0.001 or 0.01)
      - Refining steps: typically 1e6 for MuJoCo, environment-specific otherwise.
      - PPO hyperparameters: same as initial training (possibly lower learning rate).

    Theoretical guarantee (Theorem 3.6):
      Vπ*(ρ) - Vπ'(ρ) ≤ O( ε/(1-γ)² · ||dρπ* / dρπ̂||∞ )
      where π̂ is the equivalent policy of MaskNet-based sampling (better than π by Lemma 3.5),
      and π' is the refined policy. The bound is tighter than using random explanation.

    ============================================================================
    5. ENVIRONMENT WRAPPERS – envs/*.py
    ============================================================================
    Each wrapper must implement:
      - reset_to_state(state): restore the simulator to a previously saved state.
        For MuJoCo: save/restore qpos, qvel (similar to Ecoffet et al. 2019).
        For other envs: save/restore the full internal state.
      - get_state(): return the current full state (for saving critical states).
      - step(action): standard Gym interface.
      - reset(): default reset.

    Specific environments:
      a) MuJoCo (Hopper-v3, Walker2d-v3, Reacher-v2, HalfCheetah-v3):
         - Use Gym/MuJoCo. State saving via sim.get_state().
         - Sparse reward variants: modify reward to give x-position only if x > threshold
           (Hopper/Walker2d: x>0.6; HalfCheetah: x>5).
      b) Selfish Mining: Use environment from https://github.com/roibarzur/pto-selfish-mining.
         - State: chain state vector. Action space: {Adopt, Reveal, Mine}.
         - Target agent: PPO with 4-layer MLP (hidden 128 each).
      c) CAGE Challenge 2: Use environment from https://github.com/cage-challenge/cage-challenge-2
         and champion agent from https://github.com/john-cardiff/-cyborg-cage-2.
         - Action space: 11 discrete actions (Monitor, Analyze, Decoy*, Remove, Restore).
         - Target agent: PPO-based blue agent.
      d) Autonomous Driving (MetaDrive): Use "Macro-v1" environment from MetaDrive.
         - State: vector of BEV + sensor info. Action: [steering, acceleration, brake] ∈ [-1,1]².
         - Target agent: PPO following DI-drive implementation.
      e) Malware Mutation (MalConv): Use gym environment from https://github.com/bfilar/malware_rl.
         - State: feature vector of PE file. Action space: 16 discrete mutation actions (Table 2).
         - Target agent: PPO via Tianshou.
         - Reward: evasion score difference + bonus 10 for successful evasion.

    ============================================================================
    6. BASELINE METHODS (for validation)
    ============================================================================
    - PPO fine-tuning: Continue training target agent with lower learning rate, no initial state change.
    - StateMask-R: Use StateMask for explanation + refining (from their code).
    - JSRL (Jump-Start RL): Use implementation from https://github.com/steventango/jumpstart-rl.
    - Self-Imitation Learning (SIL): Prioritize good past experiences in replay buffer (Oh et al., 2018).
    - Random explanation: Replace MaskNet with random importance scores for critical state selection.
