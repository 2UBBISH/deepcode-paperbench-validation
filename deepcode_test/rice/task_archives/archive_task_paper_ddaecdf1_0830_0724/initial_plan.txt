  implementation_components: |
    ==============================
    COMPONENT 1: Mask Network (MaskNet)
    ==============================
    Purpose: Learn a state-dependent masking policy that identifies critical steps.
    Location: rice/mask_net.py

    Architecture:
      - Input: state vector s (plus optionally action a, but paper simplifies to state only).
      - Output: probability ξ(s) = P(a_e=0 | s) (keep original action).
        Mask probability = 1 - ξ(s).
      - Network: MLP with 2 hidden layers of 256 units, ReLU activations, softmax over 2 outputs (keep/blind).
        (Paper uses similar structure to target agent; for MuJoCo, target is PPO policy; mask net can be smaller MLP.)

    Training Algorithm (simplified StateMask with intrinsic reward):
      - The mask network acts as a policy π_mask(a_e | s) where a_e ∈ {0 (keep), 1 (blind)}.
      - Perturbed policy π̄: at state s, with prob ξ(s) sample from target π(a|s), else sample from uniform random π^r.
      - Collect trajectories using π̄ in the environment. For each step, reward = r_env + α * r_intrinsic,
        where r_intrinsic = 1 if a_e = 1 (blind) else 0. (Encourages masking without sacrificing return.)
      - Update mask network using PPO (or simple policy gradient) to maximize expected discounted sum of augmented rewards.
      - Hyperparameter α = 0.0001 (Table 3) balances environment return vs. masking encouragement.
      - Train for a fixed number of environment steps (e.g., 3e5 for MuJoCo, see Table 4).

    Key formulas:
      - Perturbed policy: π̄(a|s) = ξ(s) π(a|s) + (1-ξ(s)) π^r(a|s)
      - Performance bound (Theorem 3.3): η(π̄) ≤ η(π) under Assumption 3.1 (random actions never better).
      - Fidelity = (η(π) - η(π̄)) / η(π). Higher is better (perturbation doesn't hurt much).

    ==============================
    COMPONENT 2: Explanation Extraction
    ==============================
    Purpose: Use trained mask network to assign importance scores to states and identify critical steps.
    Location: rice/explanation.py

    Algorithm:
      1. For a given trajectory τ = (s_0, a_0, r_0, ..., s_T), compute importance I(s_t) = 1 - ξ(s_t) (probability of blinding).
         Higher I means more critical (action matters more).
      2. Alternatively, use the mask network's Q_diff approximation: I(s_t) ∝ Q_diff(s_t, a_t) = Q^π(s_t, a_t) - E_{a'}[Q^π(s_t, a')].
         The mask network implicitly learns this; we can use the logit difference before softmax as a proxy.
      3. Identify the top-k critical states per trajectory (e.g., k=1 for the most critical step).
      4. Store critical states in a buffer for the refining phase.

    ==============================
    COMPONENT 3: Random Network Distillation (RND)
    ==============================
    Purpose: Provide exploration bonus during refining to encourage diverse state visitation.
    Location: rice/rnd.py

    Implementation (Burda et al., 2018):
      - Target network: fixed randomly initialized MLP (input: state s, output: embedding vector of size 128).
      - Predictor network: trainable MLP with same architecture, trained to predict target output.
      - Bonus: r_rnd(s) = || f_predictor(s) - f_target(s) ||^2 (MSE).
      - Update predictor online during refining using collected states.
      - Normalize bonus by running mean/std for stability.

    ==============================
    COMPONENT 4: Refining Process
    ==============================
    Purpose: Improve a pre-trained target agent using critical-state resetting and exploration.
    Location: rice/refining.py

    Algorithm:
      Input: target policy π, mask network π_mask, hyperparameters p, λ, β (β=0.5 default for mixed distribution).
      1. Collect N trajectories using π. For each, use explanation module to find the most critical state s_crit.
         Store all s_crit in buffer D_crit.
      2. Define mixed initial state distribution μ:
           With probability p: sample s ~ Uniform(D_crit) and reset environment to s.
           With probability 1-p: sample s ~ ρ (default initial distribution).
         (Paper uses p ∈ {0.25, 0.5} depending on environment, see Table 3.)
      3. Refining loop (using PPO):
           For each episode:
             - Sample initial state s_0 ~ μ.
             - Reset environment to s_0 (using wrapper that restores state).
             - Run policy π (the agent being refined) to collect trajectory.
             - Compute augmented reward at each step: r_total = r_env + λ * r_rnd(s).
               λ balances exploration; values: 0.001 or 0.01 (Table 3).
             - Update π using PPO loss on collected trajectories.
             - Update RND predictor on visited states.
           Continue for K steps or until convergence.
      4. Return refined policy π'.

    Theoretical guarantee (Theorem 3.6):
      V^π*(ρ) - V^π'(ρ) ≤ O( ε/(1-γ)^2 * || d_ρ^π* / d_ρ^π̂ ||_∞ )
      where π̂ is the equivalent better policy induced by mask-based sampling (Lemma 3.5).
      The mask-based sampling reduces the distribution mismatch coefficient, tightening the bound.

    ==============================
    COMPONENT 5: Environment Implementations
    ==============================
    Location: envs/

    MuJoCo (mujoco_envs.py):
      - Use Gymnasium/MuJoCo: Hopper-v3, Walker2d-v3, Reacher-v2, HalfCheetah-v3.
      - Dense reward: default environment rewards.
      - Sparse reward: modify reward function as per Mazoure et al. (2019):
          Hopper/Walker2d: reward = x_position if x > 0.6 else 0.
          HalfCheetah: reward = x_position if x > 5 else 0.
          Reacher: no sparse variant in paper; use dense only.
      - Implement state reset: use MuJoCo's set_state(qpos, qvel) to restore exact simulator state.
        Store qpos, qvel at critical steps for later reset.

    Selfish Mining (selfish_mining_env.py):
      - Use code from https://github.com/roibarzur/pto-selfish-mining (Bar-Zur et al., 2023).
      - PPO agent: 4-layer MLP with hidden sizes [128,128,128,128].
      - Actions: Adopt l, Reveal l, Mine (3 discrete actions).
      - Reward: positive if block accepted, negative if action unsuccessful.
      - Whale transaction fee=10, prob=0.01; normal fee=1.

    CAGE Challenge 2 (cage2_env.py):
      - Use champion scheme from https://github.com/john-cardiff/-cyborg-cage-2.
      - Blue agent actions: Monitor, Analyze, DecoyApache, ..., Remove, Restore (11 actions).
      - Red agent: "B-line".
      - Trails of lengths 30, 50, 100; final reward = average across lengths.
      - Negative reward when red gains admin access.

    Autonomous Driving (autonomous_driving_env.py):
      - Use MetaDrive "Macro-v1" environment (Li et al., 2022).
      - State: vector of BEV + sensor info.
      - Action: normalized 2D vector a ∈ [-1,1]^2, converted to steering, acceleration, brake.
      - Reward: penalties for collision/out-of-road, bonuses for forward progress/speed.
      - Implementation based on DI-drive (https://github.com/opendilab/DI-drive).

    Malware Mutation (malware_env.py):
      - Use MalConv gym from https://github.com/bfilar/malware_rl.
      - State: feature vector of PE file.
      - Actions: 16 discrete mutation actions (Table 2).
      - Reward: 10 if evasion successful (score < threshold), else sc_0 - sc_t.
      - Max steps per episode: 10.
      - Note: paper identifies reward design flaws (non-Markovian, sparse). Implement both original and fixed versions.

    ==============================
    COMPONENT 6: Baselines

    Location: baselines/

    StateMask (statemask.py):
      - Use original code from https://github.com/nuwuxian/RL-state_mask.
      - Train mask network with their objective (maximize perturbed return + sparsity regularization).
      - For fair comparison, use same number of samples as our method.

    Jump-Start RL (jsrl.py):
      - Use implementation from https://github.com/steventango/jumpstart-rl.
      - JSRL initializes the agent near critical states using a guide policy.
      - Adapt to our environments.

    Self-Imitation Learning (sil.py):
      - Implement SIL (Oh et al., 2018): prioritize positive-advantage transitions in replay buffer.
      - Use with PPO: add SIL loss term to PPO objective.

    PPO Fine-tuning (ppo_finetune.py):
      - Continue training the target agent with PPO, lower learning rate (e.g., 3e-5).
      - No state resetting, no exploration bonus.
